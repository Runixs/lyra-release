# Lyra releases

This repository holds released builds of Lyra only: the Windows (and later macOS) installers, the remote `lyra-daemon` for Linux, `SHA256SUMS.txt`, and the signed update feed the app reads. The source code is not here.

Every release here is a copy of the same release made from the source repository: the same tag, notes and files. Check a download against `SHA256SUMS.txt` in the same release.

From Lyra 0.2.11 on, the app's update check reads this repository.
