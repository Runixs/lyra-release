Agents

Agents shows where agents such as Claude Code, Codex and OpenCode (programs that read and write code as they work) are installed on each computer. Under each agent there is a profile (a record of which agent to run and with which settings). To learn what a profile is, see Profiles and agents.

The left side of the screen is the Machines list, and the right side is the panel of the one machine you pick. The list shows this computer (localhost), the WSL distributions you added, and the servers you registered, in that order. Each row has a name, a WSL or SSH mark, and the state with the number of agents found (“Connected · 2”). The state of a server is Connected, Disconnected or Not checked yet, and that of a WSL distribution is Running, Stopped or Starting.

The panel on the right has two parts.

  • Installed: The agents found on that machine appear one per row, and the profiles copied from an agent appear indented right below it. A row has a name, a version, a Use switch and a ⋯ button.
  • Supported: Agents that Lyra supports but that are not on that machine. Each row has Not installed (or Not on the path) and a How to install button.

The pictures on this page were captured with sample data.

Choose a machine and find the agents again

Section titled “Choose a machine and find the agents again”
  1. In the Machines list on the left, select a machine.
  2. Select Check now in the header of the right panel. The button’s name is “Check the agent runtimes on (machine) now”.
  3. While it looks, the button shows a reading mark. When it finishes, the rows are replaced with the new result.
  • For a server that is not connected, Connect appears instead of Check now, and for a stopped WSL distribution, Start. When you select it, Lyra connects or starts it the same way as in Remote or WSL, and then finds the agents. If that fails, the reason appears under the panel header.
  • A server that you registered but never connected has the state Not checked, and it says “The server “…” has never been connected, so its agents have not been read. Press [Connect] to read them.”
  • The rows of a machine that is not connected or is stopped are dimmed and locked. The switch and ⋯ cannot be used, and selecting a name shows only what was seen last.
  • If nothing is found on a machine, it says “No agents were detected.” under Installed.
  • When the agents could not be found, the state in the panel header becomes Not checked. Select the text to see the reason. For a server there is also an Open Remote button, which takes you to Remote.
  • If a version check did not finish in time, the expanded part of that agent row says “The (agent) version check on (machine) did not finish within (N) seconds. Press [Check now] to check again.”
  • If OpenCode is older than 2.0.0, the line under its row says “OpenCode (version) on (machine) ((path)) is older than the version Lyra needs (2.0.0 or later), so Lyra cannot open sessions with this OpenCode. Run opencode upgrade on that computer, then press [Check now].”

See what an agent row holds

Section titled “See what an agent row holds”

Select the name of an agent or profile and it expands below. Select it again to fold it.

Item Meaning
Run command The command the profile runs
Pre-run command Set if there is one, None if not
Path The path of the executable that was found
Check One of Confirmed, Not on the path, Not checked, Needs fixing, Not checked yet

See a machine’s details

Section titled “See a machine’s details”

Select the machine’s name in the panel header to expand it.

Item Meaning
Connection localhost on this computer. SSH host, Port and User on a server
OS The machine’s operating system
Lyra Appears only on this computer. The app version
lyra-daemon · Protocol The version and protocol of the lyra-daemon running on that machine

When a value is not known, it says Not checked yet. When you expand a server, the server’s lyra-daemon records appear too. Their meaning is in What you see in an expanded row on the Remote page.

If this computer’s lyra-daemon has a different version from the app, a Differs from the app version (…) mark and an Update lyra-daemon button appear. When you select the button, the window “Restart this computer’s lyra-daemon?” shows the running version, the version bundled with the app, and how many sessions and terminals will end. Select Restart lyra-daemon and this computer’s sessions and standalone terminals end. To back out, select Cancel.

Turn a profile on or off

Section titled “Turn a profile on or off”

Each agent and profile row has a switch at the right of its version. The switch’s name is “Use (name)”, such as “Use Claude Code”. The switch changes only that profile on that machine.

  1. Select the switch to turn it on or off.
  2. The new value is saved at once.
  • On a row of a locked machine, the switch cannot be used.
  • If it cannot be saved, the reason appears under the list.

Edit a profile

Section titled “Edit a profile”
  1. Select ⋯ (its name is “More actions for (name)”) at the end of an agent or profile row and choose Edit profile…. The Edit profile window opens.
  2. On the Settings tab, edit the fields.
  3. Select Save. The window closes when it is saved.

Next to the window title, it shows which computer’s profile this is. If you try to close it with changed input, it says “There is input that has not been saved” and you choose Stay or Discard.

Field Meaning
Profile name The name of the profile. An agent’s default profile cannot be renamed, and a profile made by copying can
Agent Which agent the profile is for
Icon · Color The picture and color that help you recognize the profile. Choose the color from Agent default, Blue, Violet, Teal, Green, Amber, Rose
Model name (optional) If you enter a name, it is used as is and the model list is not looked up. Leave it empty to choose automatically (Look up automatically)
Executable (absolute path) The full path of the agent’s executable
Claude settings file Appears only on a Claude Code profile. Before a run, Lyra only checks that the file exists and does not read its contents
Pre-run command A command run on that computer just before the agent starts. If it fails or does not finish within 30 seconds, the session is not opened. Do not write a password or token in it; read it from a file or the keychain
Base arguments Enter one argument per line
Permission mode arguments Expand it to edit Extra arguments for unrestricted mode and read Extra arguments for restricted mode (read-only)
  • On a profile of a Windows computer, the Pre-run command field is locked and says “Pre-run commands cannot be used on Windows, so this field is locked. Set it on a macOS or Linux machine.”
  • Whether there is a Pre-run command shows in the expanded row, under Pre-run command (Set or None).
  • Selecting Reset to the default command (Reset to the original profile’s command for a copied profile) saves at once so that this profile follows the default command.
  • If a field does not fit when you save, Lyra tells you which field has the problem and puts the cursor in it. For example, if the executable is not a valid full path, it says “Check the executable. A valid absolute path is required.” If the arguments do not fit, it says “Check the command arguments. {model} is required exactly once. …”
  • The row at the bottom shows the result of the last test. You can Save even if you have not tested.

Add a profile

Section titled “Add a profile”

You make a new profile by copying a default profile. Use this when you want to use the same agent with another model or another run command.

  1. Select Add agent/profile in the panel header and choose Add profile…. You can also choose Copy profile… in the ⋯ of the row you want to copy. Then the window opens with that agent already chosen.
  2. In the Add profile window, enter a Profile name and choose in Agent which agent to copy.
  3. Edit the fields you need and select Save.
  • If no agent was confirmed on that machine, or the machine is locked, Add profile… cannot be selected. Copy profile… on the row of an agent that is not confirmed cannot be selected either.
  • If the profile was created but its run settings could not be saved, it says “The (name) profile was created, but its run settings could not be saved. Save again in this window, or reopen the profile to finish the settings.”

Test the run command

Section titled “Test the run command”

You can try the values exactly as you entered them, before saving.

  1. In the Edit profile window, open the Test tab.
  2. Select Start test. To run it again, select Test again. To end it, select End test.
  3. Look at the state of the three steps. The order is Pre-run command, Agent start, Model check.
Step state Meaning
Waiting Not done yet
In progress It is running
Done It finished
Skipped It was not done
Failed It failed
Needs a look It finished, but there is something to check
  • The Pre-run command shows its output, and a bar shows how much time has passed against 30 seconds.
  • When Agent start happens, the real agent terminal opens below.
  • When it ends, N models found appears. If you entered a model name, it tells you the list was not looked up. If there are no models, it says “No models were found. Check the terminal’s sign-in prompt and the agent settings.”
  • The row at the bottom shows the last result as one of Last test passed, The last test found no models, Last test failed, Last test cancelled. If you change the input after that, “The values changed after this test” is added.

Delete a profile

Section titled “Delete a profile”

Only a profile made by copying can be deleted. The ⋯ of a default profile has no Delete.

  1. Choose Delete in the ⋯ of the copied profile’s row. You can also open the profile window and select Delete at the bottom.
  2. In the Delete profile window, select Delete. To back out, select Cancel.

To use a deleted profile again, you have to add the profile anew.

Install an agent

Section titled “Install an agent”
  1. Select Add agent/profile in the panel header and choose Install agent…. Selecting How to install on an agent row under Supported opens the same window.
  2. The window has one row each for Claude Code, Codex and OpenCode. A row shows the version if it is installed, or Not installed if it is not.
  3. On the row of the agent to install, select Install instructions. When an install command appears, copy it with the copy button and run it in that computer’s terminal. If there is no command, select Open under Official guide to open the guide page.
  4. After installing, select Check now on the same row to find it again.

Above a command, it says where to run it (PowerShell, a macOS terminal, a Linux terminal) and the computer’s name.

Turn the cache timer on or off

Section titled “Turn the cache timer on or off”

Here you decide whether the time left on the prompt cache (what an agent keeps of the start of a conversation for a while, which lowers the cost of the next message) shows as a timer on the session rows of Open a Session. It exists only for Claude Code and its profiles.

  1. Open the ⋯ of the row of Claude Code or one of its profiles.
  2. Select Cache timer to turn it on or off. It is saved at once.
  • It starts turned on. When it is off, no timer appears on session rows opened with that profile.
  • Claude Code decides how long the cache lasts. Lyra does not ask for a time, and the timer counts with the value Claude Code recorded.
  • A row where you ran claude directly in a terminal follows the switch of the default Claude Code profile on that machine.
  • Codex and OpenCode do not record the lifetime, so they have neither a timer nor a switch.
  • If it cannot be saved, the reason appears under that row.

Words on this screen

Section titled “Words on this screen”

See Terms for what each word means.

Word On this screen
Profile One row under Installed. There are default profiles and the copied profiles below them
localhost The first row of the machines list, the name of this computer
Pre-run command A command run just before the agent starts
Prompt cache The Cache timer switch decides whether a session row shows the time left on it
lyra-daemon Lyra’s execution engine, which runs the agents on each computer

When something goes wrong

Section titled “When something goes wrong”
What you see What to do
“No agents were detected.” Install an agent, then select Check now. See Install an agent above
Not checked in the panel header Select the text, read the reason, and find the agents again. For a server, check the connection in Remote
A row is dimmed and its switch and ⋯ are locked The machine is not connected or is stopped. Select Connect or Start in the panel header
An agent is under Supported It was not found on that machine. Install it or check the path, then find it again
The Pre-run command field is locked It is a profile of a Windows computer. Set it on a macOS or Linux computer
A notice at save time saying which field has the problem Fix the field where the cursor went
The agent ends right away See When the agent ends right away
