Split and Layout

The screen arrangement has four levels: Layout ⊃ tab group ⊃ pane ⊃ tab.

Word Meaning
Layout An arrangement that lays out several Worktrees on one screen
tab group A tab row and the body below it, bundled together. One tab group holds the tabs of one workspace
pane One region inside the body of a tab group that shows one tab
split The action of dividing a pane or a tab group in two

Even when you are looking at only one workspace, there is a tab group. Each workspace remembers its own arrangement. A Layout appears when you place two or more workspaces. Tabs belong to the workspace, not to the Layout, so changing or dissolving a Layout does not stop the tabs and terminals. A Layout is saved in the storage this app keeps on this computer (localStorage). It does not follow you to a server or another computer.

The pictures on this page were taken with sample data.

Split a pane

Section titled “Split a pane”

This divides the body of one tab (a terminal or a Session) in two so you can see both side by side.

  1. Click the terminal or Session pane you want to split.
  2. Press the keys.
Action macOS Windows
Split right ⌘D Ctrl+Shift+D
Split down ⌘⇧D Alt+Shift+D
Close split pane ⌘W Ctrl+Shift+W

Instead of keys, you can use the buttons at the top of the pane (Split right, Split down), the right-click menu inside a terminal, or the tab menu. The top of a split pane also has Remove from side-by-side view and Close split pane buttons. Neither stops the terminal or the Session. Even if you close a pane, the session keeps running. Remove from side-by-side view is also in the tab menu. Drag the border between panes to change the size. Double-click a border to make it half and half, and after you click a border, the arrow keys move it by 24 px. You move to another pane with Ctrl+Alt+arrow keys. The next and previous pane are ⌘⇧] / ⌘⇧[ on macOS and Ctrl+] / Ctrl+[ on Windows.

A split that would make a pane too small does not happen, and Lyra tells you why.

Split a tab group

Section titled “Split a tab group”

This separates one tab into a new tab group and places them side by side.

  1. In the tab menu (… or right-click), choose Split a tab group to the right or Split a tab group below.
  2. The … (Tab group menu) in the row above the tab group has the same items. It splits the tab in front of that tab group into a new tab group.
  3. You can also drag a tab and drop it on the edge of a tab group. A hint such as New tab group → or Show beside → appears where you will drop it.

You can also drag the border between tab groups to change the size, and double-click it to make it half and half.

What you can do with a tab group is in the … menu in the row above it.

Menu What it does
Set a title… Gives the tab group a title. Enter saves, Esc cancels, and if you leave it empty only the Worktree name shows. There is also Clear the title
Merge with another tab group Merges the tabs of this tab group into the tab group you choose
Move all tabs Moves all the tabs to the tab group you choose
Close tab group Does not appear when there is only one tab group

Move to a tab group, which sends a tab to another tab group, is in Tabs. If a tab group has only one last tab, that tab cannot be moved to a new tab group. The row above a tab group shows the title, the run location mark (Runs on this computer or a server name), and the project name › Worktree name.

Create a Layout

Section titled “Create a Layout”

When a Worktree is already on the screen and you place another Worktree beside it, a Layout is created right away. There is no save button.

Way 1. The explorer row menu

  1. In the explorer, click … on the row of the Worktree you want to place beside.
  2. Choose Open beside. It is placed to the right of the tab group in front now. This item does not appear for a Worktree that is already on the screen.

Way 2. The tab group menu

  1. In … in the row above the tab group, choose Open a Worktree beside…. The shortcut ⌘⇧\ (Ctrl+Shift+\ on Windows) does the same.
  2. Choose from the Find a Worktree list. One that is already on the screen is blocked with Already on this screen. If nothing matches, “No Worktree matches” appears.

Way 3. Drag and drop

  1. Press a Worktree row in the explorer and drag it to the edge of a tab group on the stage.
  2. A hint appears where you will drop it. A Worktree that is not on the screen is placed beside, and if you drop it in the middle, Replace this tab group with this Worktree swaps the Worktree of that tab group. A Worktree that is already on the screen shows as blocked.

To change a Worktree in a Layout, choose Swap Worktree… in the tab group menu, or click the Worktree name in the row above the tab group. You cannot place the same Worktree twice in one Layout.

The Layout list

Section titled “The Layout list”

Below the explorer is the Layout list. If there is no Layout at all, the list area does not appear. Once one is made, the “Saved Layouts” list appears, and if the list is empty, it says “There are no saved Layouts. Drag a Worktree from the Explorer to the edge of a tab group to create one.”

  1. Click a row in the list to open that Layout on the screen. The row that is on the screen now is highlighted. The Layout that was in front stays behind as it is.
  2. A row has a name and a small picture of the split shape, and the first nine rows show a shortcut to open them on the right (⌘1 to ⌘9, or Ctrl+1 to Ctrl+9 on Windows).
  3. Drag and drop a row to change the order.
  4. To hide the shortcuts, choose Hide shortcuts in the row menu. Go back with Show shortcuts. This setting is the same as the one on the Shortcuts page in Settings.

If you do not give it a name, the row name is taken from the names of the Worktrees inside.

Rename

  1. Choose Rename in the row menu. You can also select the row and press Enter on macOS or F2 on Windows.
  2. Enter it in Layout name and press Enter. Esc cancels. A name can be up to 64 characters. If you leave it empty, it goes back to having no name.

The row menu also has Move up, Move down, Remove tab group, and Dissolve Layout. You can also set shortcuts for the next and previous Layout, rename, dissolve, and undo dissolve, but at first they are empty.

Remove a tab group and dissolve a Layout

Section titled “Remove a tab group and dissolve a Layout”
  • Remove tab group: if you choose a Worktree in the row menu, the tab group of that Worktree leaves the Layout. In a Layout that is open on the screen, you can also use the × (Remove from Layout) in the row above the tab group, or Remove from Layout in the tab group menu. Show only this tab group opens only that one Worktree, large.
  • A Layout must have at least two tab groups. If only one is left, that Layout ends.
  • Dissolve Layout: if you choose it in the row menu, the row disappears and the notices “Layout dissolved: name” and “The tabs and terminals are still there.” appear. If you click Undo within 10 seconds, it comes back.
  • If you delete a Worktree that was in a Layout, that Layout ends by itself, and Lyra tells you: “The name Layout ended because its Worktree was deleted. The remaining tabs are on that Worktree’s screen.”

Limits

Section titled “Limits”
Limit Value
Number of Layouts you can save 256
Saved size of one Layout 64 KiB
Depth to which you can split tab groups 32 levels
Minimum size that must remain inside a tab group Terminal 40 × 8 cells, file and web 220 × 70 pixels

When you reach a limit, Lyra does not do it and tells you why. For example: “There are more than 256 Layouts, so no more can be created. Dissolve a Layout you do not use and try again.”

When it does not work

Section titled “When it does not work”
What you see What to do
“The tab group is too small to split. A terminal must keep 40 × 8 cells, and a file or web page 220 × 70 pixels.” Make the window or the tab group wider, or make another tab group smaller, then split again
“This Worktree is already in this Layout. Choose another Worktree.” Choose another Worktree
“This Layout is over the storage limit (64 KiB)” Reduce the tab groups or tabs
“The last tab of this tab group cannot be moved to a new tab group. Open another tab first.” Open one more tab, then move
“The Layout shortcut display could not be saved.” You can use the display as it changed. Check access to the storage, then change it again
A Layout in the list disappeared The last tab group may have been removed, or the Worktree may have been deleted. Try Undo in the notice above
