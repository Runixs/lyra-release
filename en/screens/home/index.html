Home

Home is what the app calls the “Lyra screen”. Like a status board at a shop entrance, it gathers what is running, what is waiting for you, and your recent projects on one page.

You open Home by selecting the Lyra logo. On macOS the logo is at the top of the left bar, and on Windows it is at the left of the title bar. The logo is named “Go to the Lyra screen”. The same three blocks also appear when you open Lyra in the left bar and have not picked a conversation yet. See Lyra for details.

Each time you enter Home, it reads the three blocks again. Each block is read on its own, so if one block fails, the others still show.

This screen was captured with sample data.

See what is running now

Section titled “See what is running now”
  1. Open Home.
  2. Look at the “Running now” block.

Each row shows a status mark, the session name, and the run location (Host). A session (one working window shared with an agent) with no name shows as “Untitled session”. The status is written in English: Working, Waiting, Idle, Done.

  • Only sessions that are open and confirmed to have a live process are listed.
  • Sessions whose state is unknown are left out. When that happens, the block says “N sessions whose state is unknown were left out of this list.”
  • These rows are for viewing only. Selecting one goes nowhere.
  • When the block is empty, it says “Nothing is running now.”

Answer what is waiting for you

Section titled “Answer what is waiting for you”
  1. In the “Waiting for you” block, find the row to answer. When there are requests, the count is added to the title, as in “2 waiting for you”.
  2. Read the row’s kind mark (Approval or Question), its title, and its time. If the action cannot be undone, a Cannot be undone mark is added, so look carefully.
  3. Select Answer.

The Inbox screen opens. The row you selected is not picked there, so find the same row on that screen and answer it. This count is the same number as the Inbox number in the left bar.

When the block is empty, it says “Nothing to answer.”

Open a recent project

Section titled “Open a recent project”
  1. In the “Recent projects” block, find the project row. Each row shows the project name and the run location.
  2. Select Open project.

The project opens on the Projects screen.

  • Up to 5 rows are shown. If there are more, the block only tells you how many: “There are N more projects.” See the rest in the explorer on the Projects screen.
  • If you have no projects, the block says “No projects are registered. Register a repository and you can create a workspace.” To register one, see First Session.

Read again when a part fails

Section titled “Read again when a part fails”
  1. Read the sentence in the block that failed. “The list could not be read.” is followed by the reason.
  2. Select Read again in the same block.

When only part of a block was read, it says “Some rows could not be read, or there are more rows to read.” While a block is being read, a reading mark shows.

Words on this screen

Section titled “Words on this screen”

See Terms for what each word means.

Word On this screen
session One row of “Running now”
Working · Waiting · Idle · Done The state of a session
Approval · Question The kinds in “Waiting for you”
Cannot be undone The mark for an action that cannot be undone once it is done
project One row of “Recent projects”

When something goes wrong

Section titled “When something goes wrong”
What you see What to do
“The list could not be read” in a block Select Read again. If it keeps happening, see Troubleshooting.
“Some rows could not be read, or there are more rows to read.” Select Read again, or open Home again.
A session exists but has no row Sessions whose state is unknown are left out of this list. Look for it on the Projects screen.
