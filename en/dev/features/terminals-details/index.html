Terminals details

This content is not available in your language yet.

Terminals의 찾아보기 표입니다. 모든 연산은 Operations, 모든 오류 코드는 Errors가 정합니다. 여기에는 이 기능의 것만 한 줄씩 적습니다.

연산

섹션 제목: “연산”

모두 window bridge의 lyra:call로 부를 수 있습니다. Worker 터미널의 정산(terminal.release · terminal.reuse · terminal.reclaimable)은 Orchestration에 있습니다.

연산 한 줄
terminal.list 셸 터미널의 목록을 읽습니다. scope: "free"로 Project에 속하지 않은 터미널만 읽을 수 있습니다.
terminal.show 터미널 하나를 읽습니다.
terminal.shells 작업 자리의 Host가 내놓는 셸 선택(defaultShell, 셸마다 available과 이유)을 pty.capabilities로 지금 읽습니다.
terminal.split 새 셸 터미널을 엽니다. 원래 칸이 있으면 그 폴더에서 엽니다. requestId가 필요하고 shell · distributionId · title · reopenTerminalId를 받습니다.
terminal.attach · terminal.detach PTY에 보기를 붙이거나 뗍니다. 붙을 때 프로세스를 만들지 않습니다.
terminal.snapshot 화면의 지금 모습을 임시 보기로 읽습니다.
terminal.subscribe 출력 채널을 구독합니다. viewRef · afterSeq로 이어 받습니다.
terminal.input 키 입력을 보냅니다. source는 human 또는 automatic만 받습니다. Worker Session 터미널에 사람이 넣은 입력은 배차 장부에 먼저 적고 나서 보냅니다. 자동 입력은 사람의 입력으로 적지 않습니다.
terminal.compose 작성 칸의 글을 Session의 터미널로 보냅니다. 보기의 주인 · 버전 · Session 결속을 확인합니다.
terminal.respond 화면에서 온 터미널 질의(queryGeneration)에 자동으로 답을 보냅니다.
terminal.resize 열과 줄(cols · rows, 0은 거절)을 바꿉니다. 입력 임대를 가지지 않아도 됩니다.
terminal.claim 입력 임대를 가집니다(pty.claim). Worker Session의 터미널이면 그 Worker의 상태 채널을 사람이 이어받은 것으로 바꿉니다.
terminal.status PTY의 상태를 읽습니다.
terminal.observed-agent · terminal.agent-evidence 셸 안에서 도는 에이전트를 본 것과, 그 멈춘 차례가 daemon의 메모리에 남긴 화면 줄을 읽습니다.
terminal.caller 로컬 셸에 있는 이름표(LYRA_TERMINAL_ID · LYRA_TERMINAL_INCARNATION · LYRA_TERMINAL_NONCE)에서 어느 Session으로 행동하는지 풉니다.
terminal.send 셸에 글을 씁니다. 모든 바이트가 OS에 쓰인 뒤에 답합니다.
terminal.read 마지막 줄들을 읽습니다.
terminal.close 셸을 닫습니다.
terminal.rename 저장된 제목만 바꿉니다.
file.open-terminal 파일 위치에서 터미널을 엽니다.

terminal.caller와 lyra terminal의 열네 동사(list · show · shells · split · attach · reopen · detach · release · reuse · create · send · read · close · rename)는 lyra가 부릅니다.

입력의 제한

섹션 제목: “입력의 제한”
  • scope는 free만 받고, terminal.split · terminal.shells · terminal.list에만 줄 수 있으며, workspaceId · sessionId와 함께 줄 수 없습니다.
  • shell · distributionId는 terminal.split만, title은 terminal.split · terminal.rename만, limit은 terminal.read만 받습니다. 어기면 invalid-input입니다.
  • terminal.split에 sourceTerminalId와 terminalId를 함께 줄 수 없습니다.
  • 앱이 고른 distributionId는 엔진이 받아 그 배포판에서 셸을 엽니다. 에이전트가 CLI bridge로 보낸 distributionId는 Workspace의 대상 밖으로 셸을 옮기므로 두 길 모두에서 permission-denied(option-unlisted)로 거부합니다(cli_bridge_policy.rs check_options).

셸 터미널의 상태

섹션 제목: “셸 터미널의 상태”

ShellTerminalState입니다. session_shells의 본문에 있습니다.

상태 뜻
Opening PTY를 여는 중입니다.
Attached PTY가 살아 있고 보기가 붙었습니다.
Detached PTY는 살아 있고 보기만 떨어졌습니다.
Closing 명시적으로 PTY를 닫는 중입니다.
Closed PTY의 종료를 확인했습니다.
Failed 원인과 함께 실패했습니다.

한 줄(ShellTerminal)은 Host의 터미널 번호 id, 속한 Session(sessionId, 독립 셸이면 없음), 실행을 가르는 수 incarnation, 작업 자리 workspaceId, 실행 hostId, 확인된 작업 폴더 cwd, Host의 PTY 참조 remoteTerminalRef, PTY를 연 daemon의 기동 참조 daemonInstanceRef를 지닙니다.

한도

섹션 제목: “한도”
값 크기
출력 보기의 창 128 KiB(VIEW_WINDOW_BYTES)
terminal.send의 글 64 KiB 이하(MAX_SEND_BYTES)
terminal.read의 줄 기본 120, 최대 2000
Layout 저장 변경 250 ms 뒤, 늦어도 1초(LAYOUT_SAVE_DELAY_MS · LAYOUT_SAVE_MAX_MS)
Windows Host의 셸 이름 powershell · cmd · git-bash(기본 cmd). powershell-workflow는 사람에게 보이지 않음

오류 코드

섹션 제목: “오류 코드”

이 기능의 코드 가운데 사람이 마주치는 것만 적습니다. 전체는 Errors입니다.

코드 뜻
terminal.view-stale · terminal.view-not-owner 보기가 낡았거나 다른 손님의 것입니다.
terminal.card-view-locked terminal.compose를 받을 수 없습니다. 그 Session에 에이전트의 대화 신원(providerBinding)이 없습니다.
terminal.stream-invalid · terminal.stream-lost · terminal.stream-gap · terminal.stream-version · terminal.stream-record-too-large · terminal.sequence-ahead 출력 채널이 틀렸거나 끊겼거나 건너뛰었거나, 버전이나 크기가 맞지 않습니다.
terminal.daemon-instance-changed · terminal.incarnation-changed · terminal.execution-binding-changed PTY를 쥔 daemon이나 실행이 바뀌었습니다.
terminal.host-mismatch · terminal.location-invalid · terminal.descriptor-invalid 터미널의 Host · 실행 위치 · 서술자가 맞지 않습니다.
terminal.pty-missing · terminal.exited · terminal.not-running 셸이 Host에 없거나 이미 끝났습니다.
terminal.session-invalid · terminal.session-pty-absent · terminal.session-pty-unavailable Session에 묶인 PTY를 찾을 수 없습니다.
terminal.split-unconfirmed · terminal.send-unconfirmed · terminal.detach-unconfirmed · terminal.snapshot-unconfirmed Host의 답을 받지 못해 결과를 모릅니다.
terminal.split-unavailable · terminal.split-store-unavailable · terminal.split-store-conflict 나누기를 할 수 없거나, 요청 기록(home_terminal_splits)이 막혔거나 어긋납니다.
terminal.send-rejected · terminal.send-unavailable · terminal.read-unavailable · terminal.snapshot-unavailable · terminal.resize-unavailable 그 일을 받을 수 없습니다.
terminal.shell-unavailable 고른 셸이 그 Host에 없습니다.
caller-terminal-absent · caller-terminal-elsewhere · caller-context-invalid · caller-terminal-ended · caller-terminal-unknown terminal.caller가 터미널을 Session으로 풀지 못한 이유입니다.

저장소 버전

섹션 제목: “저장소 버전”

home_terminal_splits는 lyra_schema_versions의 구성 요소 home_terminal, 버전 1입니다. session_shells는 Session 표와 같은 구성 요소 session(버전 3)에 속합니다.
