Projects and Workspaces details

This content is not available in your language yet.

Projects and Workspaces의 찾아보기 표입니다. 모든 연산은 Operations, 모든 오류 코드는 Errors가 정합니다. 여기에는 이 기능의 것만 한 줄씩 적습니다.

연산

섹션 제목: “연산”

모두 window bridge의 lyra:call로 부를 수 있습니다. 목록 읽기(project.list · workspace.list)는 cursor · limit으로 쪽을 나눕니다.

연산 한 줄
project.list · project.show Project를 읽습니다. project.list는 hostId로 거르고, project.show는 refreshBranchCleanups로 Host에서 남긴 브랜치의 영수증을 다시 읽습니다.
project.scan 폴더가 Git 저장소인지와 하위 폴더를 읽습니다. 아무것도 바꾸지 않습니다.
project.add 폴더를 Project로 등록합니다.
project.clone URL을 Host에 복제하고 등록합니다.
project.create 새 폴더(git이 참이면 Git 저장소)를 만들고 등록합니다.
project.find-repositories 폴더 아래의 Git 저장소를 찾습니다. 이미 등록된 것은 projectId를 달아 돌려줍니다.
project.location.add 같은 Project에 다른 체크아웃 위치를 더합니다. expectedRevision이 필요합니다.
project.update 이름, worktreeBasePath, appearance를 바꿉니다. expectedRevision이 필요합니다.
project.remove Project와 작업 자리 기록을 장부에서 지웁니다. 폴더는 지우지 않습니다. confirmation: "yes"가 필요합니다.
project.prepare-status 위치의 준비 파일과 동의의 상태를 읽습니다.
project.prepare-trust · project.prepare-trust-clear 준비 명령의 동의를 주거나 거둡니다.
git.branches Project 위치의 브랜치 목록을 Host에서 읽습니다.
workspace.list · workspace.show 작업 자리를 읽습니다. 목록은 워크플로 실행의 작업 자리를 만드는 중인 것까지 빼고(워크플로 화면에만 보입니다), 지우는 중(removing)과 남은 것(leftover)을 행마다 답합니다.
workspace.create Worktree 또는 Workspace를 만들고 준비를 시작합니다. baseRef · branchName · reuseBranch · setup(run · skip) · issue를 받습니다.
workspace.register 이미 있는 linked worktree를 selectedNativePath로 등록합니다. 준비 명령은 돌리지 않습니다.
workspace.resume 멈춘 준비를 이어서 합니다.
workspace.rename 표시 이름만 바꿉니다. 경로와 브랜치는 그대로입니다.
workspace.remove 작업 자리를 지웁니다. 입력은 아래 표에 있습니다.
workspace.branch-merged 만든 브랜치가 병합됐는지와 병합되지 않은 커밋 수를 읽습니다. 지울 브랜치가 없으면 branch: null입니다.
workspace.remove-branch 남긴 브랜치를 영수증과 머리 커밋이 같을 때 지웁니다.

workspace.remove의 입력

섹션 제목: “workspace.remove의 입력”
입력 뜻
confirmation "yes"여야 합니다.
force 저장하지 않은 변경을 알고도 지웁니다.
keepBranch · deleteBranch 만든 브랜치를 남기거나, 영수증과 머리 커밋(expectedHead)을 걸고 강제로 지웁니다. 둘을 함께 보내거나 deleteBranch에 expectedHead가 없으면 invalid-input입니다.
listOnly 폴더는 두고 등록만 지웁니다. deleteBranch와 함께 보낼 수 없습니다.
forgetUnknown 끝을 모르는 삭제 기록을 잊습니다. expectedRevision이 필요하고 다른 선택과 함께 보낼 수 없습니다.

작업 자리의 종류

섹션 제목: “작업 자리의 종류”
WorkspaceKind 화면 디스크 지울 때
LyraWorktree Worktree Lyra 폴더를 지우고, 만든 브랜치는 선택에 따라 지우거나 남깁니다.
ExistingWorktree Worktree 사람 Lyra가 디스크를 갖지 않습니다(lyra_owns_disk가 거짓).
PrimaryCheckout 원본 사람 지우지 않습니다. Project의 뿌리 자리는 workspace-root-kept로 거절하고, Project를 지울 때만 장부에서 사라집니다.
Folder 폴더 사람 이름이 붙은 추가 Workspace는 그 id만 지웁니다. 이름 없는 뿌리는 PrimaryCheckout과 같습니다.

준비 상태

섹션 제목: “준비 상태”
SetupState 경계의 철자 뜻 Session을 받음
Creating creating 만들 권리를 얻고 경로와 Git 여부를 확인하는 중입니다. 아니요
Preparing preparing 고정된 계획의 다음 단계를 돌리는 중입니다. 예
Ready ready 모든 단계가 끝났습니다. 예
Failed failed 첫 단계나 생성이 실패했습니다. 자리는 보존됩니다. 아니요
Partial partial 하나 이상 성공한 뒤 다음 단계가 실패했습니다. 아니요

단계 하나(SetupStepState)는 Pending · Running · Succeeded · 실패로 갑니다. Running은 답을 기다리는 단계이고, 답 없이 끊기면 결과 모름 실패로 둡니다. 성공한 단계는 같은 자리에서 다시 돌리지 않습니다. 계획은 만들 때 고정하고 Project의 나중 명령으로 바꾸지 않습니다.

지운 결과

섹션 제목: “지운 결과”
답 뜻
status: "unregistered" 등록을 지웠습니다. diskRemoved, branchDeleted, branchPreserved와 그 이유(reason), branchHead, cleanupRef가 따라옵니다.
workspace-dirty 저장하지 않은 변경이 있어 폴더와 등록을 그대로 뒀습니다.
workspace-clean-unknown 깨끗한지 확인하지 못해 그대로 뒀습니다.
workspace-remove-incomplete 다 지우지 못했습니다. 남은 경로(remainingPath)를 비우고 다시 지웁니다.

답에는 멈춘 Session과 셸의 목록(stopped)이 붙습니다. reason이 branch-restore-failed이면 branchRootPath가 붙어, 되돌릴 자리를 알려 줍니다.

탐색기는 남긴 브랜치를 목록으로 보이지 않습니다(ForceDelete.tsx의 주석). 프로젝트 설정의 남긴 브랜치가 그 영수증을 보입니다.

장부의 칸

섹션 제목: “장부의 칸”
값 뜻
Project.id · name · revision Project ID, 이름, 바뀔 때마다 오르는 버전(project-<n>)
Project.worktree_container 등록할 때 고정되는 워크트리 통 이름
Project.locations[] 위치: hostId, executionLocationId, rootPath, rootIsGit, setupPlan, gitRemoteIdentity, worktreeBasePath
Project.prepare_trust 준비 명령의 동의와 버전
Project.appearance 프로젝트 설정에서 고른 아이콘과 색. 없으면 Host 표시
Workspace.kind · setup_state · setup_plan · setup_progress 종류, 준비 상태, 고정된 계획, 단계별 진행
Workspace.path · root_path 실제 폴더(Host가 돌려준 철자), 원본 checkout
Workspace.display_name · folder_name · branch · creation 표시 이름, 이름 붙은 Workspace의 이름, 체크아웃된 브랜치, 만들 때 요청한 브랜치 선택
Workspace.failure · retained_workspaces 실패와, 번호를 붙이는 동안 남겨 둔 경로와 브랜치

저장소 버전은 lyra_schema_versions의 구성 요소 project, 버전 5입니다. 버전 4가 삭제 기록(removals)을, 버전 5가 아이콘과 색(appearance)을 더했고, 낮은 버전의 엔진이 새 장부를 읽다 틀리지 않고 처음부터 거절하도록 번호를 올렸습니다(STATE_FORMAT_VERSION의 주석).

오류 코드

섹션 제목: “오류 코드”

이 기능의 코드 가운데 사람이 마주치는 것만 적습니다. 전체는 Errors입니다.

코드 뜻
project-not-found · workspace-not-found 없는 Project · 작업 자리입니다.
project-name-invalid · workspace-name-invalid 이름이 규칙에 맞지 않습니다.
project-base-path-invalid 워크트리 위치가 쓸 수 없는 경로입니다.
project-location-invalid · project-root-invalid 위치나 뿌리 폴더를 확인하지 못했습니다.
project-setup-invalid 준비 명령이 규칙에 맞지 않습니다.
project-has-live-sessions 쓰는 중인 작업 자리가 있어 Project를 지울 수 없습니다.
project-branch-cleanup-unsettled 남긴 브랜치의 강제 삭제가 끝났는지 몰라 Project를 지울 수 없습니다.
workspace-root-not-git Git이 아닌 Project에 Worktree를 만들 수 없습니다.
workspace-root-kept Project의 뿌리 작업 자리(원본 checkout, 또는 Git이 아닌 Project의 폴더)는 지우지 않습니다.
workspace-state-conflict · workspace-in-use · workspace-removing 작업 자리의 지금 상태가 그 일을 받지 않습니다.
workspace-already-registered · workspace-not-a-linked-worktree 등록하려는 폴더가 이미 있거나 linked worktree가 아닙니다.
workspace-exists-with-other-branch 같은 이름의 작업 자리가 다른 브랜치로 있습니다.
workspace-branch-options-invalid 만들 때 reuseBranch와 branchName을 함께 주었거나 baseRef 없이 주었거나, 뿌리 작업 자리에 브랜치 선택을 주었습니다. 지울 때 어긋난 브랜치 선택은 invalid-input입니다.
setup-plan-changed · setup-nothing-to-resume · setup-step-outcome-unknown · setup-interrupted 준비를 이어 갈 수 없거나, 단계의 결과를 모르거나, 끊겼습니다.
prepare-untrusted · prepare-plan-changed · prepare-trust-revision-conflict 준비 명령의 동의가 없거나, 사람이 본 명령과 지금 명령이 다르거나, 동의의 버전이 어긋납니다.
prepare-file-invalid · prepare-file-unreadable .lyra/config.yaml이 준비 목록으로 올바르지 않거나, 읽지 못했거나 없음을 확인하지 못했습니다.
branch-cleanup-not-found · branch-cleanup-not-eligible · branch-head-changed · branch-checked-out · branch-repository-changed · branch-restore-failed · branch-delete-time-limit 남긴 브랜치를 지울 수 없는 이유입니다. 영수증이 없거나 지울 수 없는 상태, 머리 커밋이 움직임, 어느 worktree에 체크아웃됨, 다른 저장소임, 되살리기 실패, Project를 지우는 시간이 다 됨 순입니다.
project-identity-changed · project-registration-changed 복제한 사본이 확인한 저장소가 아니거나, 복제하는 동안 등록이 바뀌었습니다. 사본은 남기고 아무것도 등록하지 않습니다.
project-appearance-invalid 고른 그림이 정해진 아이콘, 이모지 하나, 작은 정사각 PNG가 아닙니다.
revision-conflict 장부의 버전이 어긋납니다. 다시 읽고 시도합니다.
project-store-unreadable · project-store-unwritable 장부를 읽거나 쓰지 못했습니다.
project-remote-answer-invalid Host의 답이 약속한 모양이 아닙니다.
