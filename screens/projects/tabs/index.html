탭

가운데 무대는 탭 그룹(탭 줄과 그 아래 본문을 묶은 것)으로 이루어집니다. 탭 줄에는 Session, 터미널, 파일, 웹 페이지, 시리얼 탭이 놓입니다. Session 탭은 Session 열기에 있습니다. 이 페이지는 나머지 탭을 다룹니다. 탭은 Layout이 아니라 작업 자리에 속합니다. 화면 배치를 바꿔도 탭 안의 터미널은 멈추지 않습니다.

이 페이지의 그림은 예시 데이터로 찍었습니다.

새 탭 열기

섹션 제목: “새 탭 열기”
  1. 탭 줄 끝의 +(새 탭)를 누릅니다. 다른 탭 그룹에서는 그 탭 그룹의 +를 누르면 먼저 그 탭 그룹으로 옮겨 간 뒤 시작합니다.
  2. 메뉴를 보고 고릅니다. 위쪽은 에이전트와 에이전트 관리…, 구분선 아래가 아래 표의 항목입니다.
메뉴 여는 탭
New Terminal 터미널. Windows에서는 명령 프롬프트(CMD)입니다
New PowerShell PowerShell 터미널. Windows에서만 나옵니다
New Git Bash Git Bash 터미널. Windows에서만 나옵니다
새 WSL 터미널 — 배포판 이름 그 배포판의 터미널. 그 작업 자리에 쓸 수 있는 배포판이 있을 때 나오고, Windows 드라이브의 작업 자리에서도 열립니다
New Markdown 새 Markdown 파일
Open Browser 웹 페이지
New Serial 시리얼 포트. 아래 “시리얼”을 보세요

없는 셸은 흐리게 보이고 이유가 나옵니다. 터미널을 열지 못하면 그 칸에 이유 문장이 나오고, 그 뒤에 닫는 단추가 있습니다. 그 밖의 호스트에서는 쓸 수 있는 셸이 새 터미널 — 셸 이름으로 나올 수 있습니다. 탭 줄의 +는 작업 자리를 고른 상태에서만 열립니다. 읽기 전용 창에서는 터미널 항목이 이유와 함께 막힙니다.

터미널은 단축키로도 엽니다. ⌘T(Windows는 Ctrl+T)는 New Terminal과 같고, 아직 탭이 없는 작업 자리의 시작 화면에서도 됩니다. 이 단축키들은 설정의 단축키 페이지에서 바꿀 수 있습니다. 이 페이지에는 처음 값을 적습니다.

터미널

섹션 제목: “터미널”

터미널은 작업 자리 폴더에서 도는 셸입니다. 본문에 글자를 입력하면 셸로 갑니다.

  • 복사와 붙여넣기: macOS는 ⌘C, ⌘V, Windows는 Ctrl+Shift+C, Ctrl+Shift+V입니다. 복사는 글자를 고른 뒤에 됩니다.
  • 오른쪽 클릭 메뉴(또는 메뉴 키, Shift+F10): 복사(글자를 고른 뒤에만), 전체 복사, 붙여넣기, 오른쪽으로 나누기, 아래로 나누기, 터미널 ID 복사, 세션 ID 복사(Session이 있을 때), 화면 지우기, 터미널 초기화, 제목 정하기…. 나누기는 나누기와 Layout에 있습니다.
  • 터미널 안 프로그램의 복사 요청: 프로그램이 클립보드에 쓰려 하면 “터미널 복사 요청” 알림이 나옵니다. 허용 여부는 설정의 터미널 항목을 따릅니다.
  • 링크: 터미널에 찍힌 웹 주소와 파일 경로는 ⌘+클릭(Windows는 Ctrl+클릭)으로 엽니다. 마우스를 올리면 「⌘+클릭으로 열기」(Windows는 「Ctrl+클릭으로 열기」)가 나옵니다. 파일 경로는 이 작업 자리 안에 실제로 있는 파일일 때만 링크가 됩니다. 있는지 확인하지 못하면 링크로 만들지 않고 「터미널에 보이는 파일 경로가 작업 자리에 있는지 확인하지 못해 링크로 만들지 않았습니다…」가 한 번 나옵니다. 같은 경로에 다시 마우스를 올려 보고, 계속되면 문제 기록에서 원인을 확인합니다. 파일이 없는 경로는 아무것도 나오지 않습니다.
  • 셸 끝내기: 터미널에서 exit를 입력하면 셸이 끝나고 칸이 닫힙니다.

탭이나 칸을 닫아도 셸은 멈추지 않습니다. 화면만 떼어 내는 것이고, 같은 터미널을 다시 열면 이어서 붙습니다. 작업 자리나 프로젝트를 삭제하면 그 안의 셸은 정해진 순서로 멈춥니다.

서버의 터미널은 연결이 끊기면 본문 위에 덮개가 나옵니다.

덮개 뜻과 할 일
“서버 “이름”의 SSH 연결이 끊겼습니다” 연결이 돌아오면 저절로 다시 붙습니다. 다시 연결을 누르면 바로 붙이고, 원격 설정 열기로 서버 연결을 확인합니다
“터미널 출력이 끊겼습니다” 출력을 보내던 연결이 닫혔습니다. 돌아오면 저절로 붙고, 다시 연결을 눌러도 됩니다
“이 터미널을 쓸 수 없습니다” 이 터미널은 더 이어 쓸 수 없습니다. 새 터미널을 엽니다
“이름의 입력이 중지됐습니다” 입력 권한이 바뀌어 전송하지 못했습니다. 다시 연결을 누릅니다

창을 닫거나 앱을 업데이트할 때

섹션 제목: “창을 닫거나 앱을 업데이트할 때”

터미널의 셸은 Lyra 창이 아니라 lyra-pty-keeper(터미널을 쥐고 있는 Lyra의 작은 프로그램)가 가지고 있습니다. 이 프로그램은 터미널이 남아 있는 동안에는 멈추라는 요청을 받아들이지 않습니다. 지금 제품에서는 앱을 업데이트해도 터미널을 새 버전으로 옮기지 않습니다. 이전 버전의 lyra-pty-keeper가 계속 터미널을 쥐고 있고, 새 엔진이 거기에 이어 붙습니다. 그래서 업데이트 때문에 터미널이 닫히지 않습니다.

Markdown

섹션 제목: “Markdown”

Markdown 탭은 작업 자리 안의 .md 또는 .markdown 파일을 편집합니다.

새 파일 만들기

  1. 새 탭 메뉴에서 New Markdown을 고릅니다.
  2. 새 Markdown 창의 경로에 “작업 자리 이름 안의 상대 경로”를 적습니다. 예시는 docs/plan.md입니다.
  3. 만들기를 누릅니다. 파일이 탭으로 열립니다. 저장하기 전까지는 초안입니다.

경로가 막히면 이유가 나옵니다. 비었거나, .md·.markdown이 아니거나, 절대 경로이거나, 작업 자리 밖으로 나가거나, 이미 있는 파일(덮어쓰지 않습니다)이거나, 이미 열려 있는 초안일 때입니다.

있는 파일 열기: 오른쪽 옆판 탐색기 탭에서 파일 줄을 누릅니다. 이름 바꾸기, 삭제 등은 오른쪽 옆판에 있습니다.

편집

  1. 탭 위쪽에서 보기 방식을 고릅니다. 원문 편집, 서식 편집, 읽기입니다. HTML이나 그림이 있어 서식으로 담을 수 없는 문서는 서식 편집이 막히고 “원문 편집에서 고치세요.“라고 나옵니다.
  2. 저장은 ⌘S(Windows는 Ctrl+S)입니다. 저장 버튼에는 상태가 나옵니다. 저장 (저장 안 됨), 충돌 — 자세히, 저장 못 함 — 다시 저장, 저장할 수 없음입니다.
  3. 찾기는 ⌘F(Windows는 Ctrl+F), 줄바꿈 켜고 끄기, 변경 사항 보기, 경로 복사는 편집기 위쪽 도구와 더 보기 메뉴에 있습니다.
  4. 저장하지 않은 탭을 닫거나 작업 자리를 떠나면 “저장하지 않은 Markdown 초안 N개” 창이 저장, 버리기, 취소를 묻습니다. 저장에 실패하면 닫지 않고 초안을 그대로 둡니다.

브라우저

섹션 제목: “브라우저”
  1. 새 탭 메뉴에서 Open Browser를 고릅니다. 단축키 ⌘⇧B(Windows는 Ctrl+Shift+B)는 이미 열린 뷰어 탭이 있으면 그것을 앞으로 가져오고, 없으면 이 창을 엽니다.
  2. Open Browser 창의 **웹 주소 (http 또는 https)**에 주소를 적고 열기를 누릅니다. http나 https가 아니면 열기가 눌리지 않습니다.
  3. 주소가 탭으로 열립니다. 이 탭들은 실행창의 뷰어 탭입니다.

시리얼

섹션 제목: “시리얼”

시리얼 탭은 작업 자리가 있는 컴퓨터에 꽂힌 USB 시리얼 포트를 터미널처럼 봅니다. 제품 버전에서는 잠겨 있습니다. 설정 › 도구 › 시리얼의 스위치를 켤 수 없어 새 탭 메뉴에 New Serial이 나오지 않습니다. 잠금이 풀린 버전에서만 아래가 보입니다.

  1. New Serial(또는 탭 메뉴의 시리얼 포트 열기)을 고르면 시리얼 포트 열기 창에 이 컴퓨터의 포트 목록이 나옵니다. 포트마다 열려 있음, 닫혀 있음, 보고 있는 보기 수, 마지막으로 입력한 쪽이 보입니다.
  2. 포트가 없으면 USB 어댑터를 꽂고 다시 찾기를 누릅니다.
  3. 포트를 고르면 탭이 열립니다. 도구 모음에는 줄 설정 칩(속도 등), Enter → 줄 끝 칩, Ctrl+C 보내기, 부트 멈춤 키, BREAK, 열린 보기 수가 있습니다.
  4. 줄 설정을 바꾸면 포트를 닫았다가 다시 엽니다. 다시 여는 동안 보드가 보낸 출력은 빠지고, 최근 60초 안에 에이전트가 입력했으면 한 번 더 묻습니다.
  5. 탭 메뉴의 시리얼 제어와 포트 닫기로 같은 동작을 키보드로 합니다.

시리얼은 이 컴퓨터의 포트만 엽니다. 서버 작업 자리에서는 열리지 않습니다.

탭 메뉴와 정리

섹션 제목: “탭 메뉴와 정리”

탭을 오른쪽 클릭하거나 …(탭 메뉴)를 엽니다. 항목은 탭 종류에 따라 다릅니다.

메뉴 하는 일
New Tab 새 탭 메뉴와 같은 목록
오른쪽에 탭 그룹 나누기, 아래에 탭 그룹 나누기 이 탭을 새 탭 그룹으로 나눕니다
탭 그룹으로 옮기기 같은 작업 자리의 다른 탭 그룹, 새 탭 그룹(오른쪽, 아래)으로 옮깁니다
나란히 보기에서 빼기 한 탭 그룹 안에서 나란히 보던 칸을 풉니다. 탭은 탭 줄에 남고 터미널과 Session은 계속 돕니다
세션 정보 정보 창을 엽니다
이름 바꾸기 아래를 보세요
세션 ID 복사(Session) 또는 경로 복사 클립보드에 복사합니다
다른 탭 닫기 이 탭 말고 같은 작업 자리의 탭을 닫습니다. Session이 들어 있으면 먼저 묻습니다
세션 닫기…(Session) 또는 보기 닫기 Session 닫기와 위 터미널을 보세요

파일 탭의 메뉴에는 탐색기에서 보기, 오른쪽 탭 닫기, 모든 탭 닫기, 탭 닫기도 있습니다.

이름 바꾸기: 탭 메뉴의 이름 바꾸기, 또는 탭을 고르고 macOS는 Enter, Windows는 F2. 이름 바꾸기 창의 탭 이름에 적고 저장을 누릅니다. 순서 바꾸기: 탭을 끌어 놓거나, 탭에 포커스를 두고 ⌘⇧PageUp / ⌘⇧PageDown(Windows는 Ctrl+Shift+PageUp / Ctrl+Shift+PageDown)을 누릅니다. 탭 사이 이동: Ctrl+Tab과 Ctrl+Shift+Tab이 다음·이전 탭입니다. 번호로는 macOS Ctrl+1Ctrl+9, Windows Alt+1Alt+9이고 9는 마지막 탭입니다. 탭을 끌어 다른 탭 그룹의 탭 줄에 놓으면 옮겨집니다. 다른 작업 자리의 탭 그룹에는 옮길 수 없습니다.
