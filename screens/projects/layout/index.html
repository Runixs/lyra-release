나누기와 Layout

화면 배치에는 네 단계가 있습니다. Layout ⊃ 탭 그룹 ⊃ 칸 ⊃ 탭입니다.

말 뜻
Layout 여러 Worktree를 한 화면에 늘어놓은 배치
탭 그룹 탭 줄과 그 아래 본문을 묶은 것. 한 탭 그룹은 한 작업 자리의 탭을 가집니다
칸 탭 그룹 본문 안에서 탭 하나를 보여 주는 한 영역
나누기 칸이나 탭 그룹을 둘로 나누는 동작

작업 자리를 하나만 보고 있을 때도 탭 그룹은 있습니다. 작업 자리마다 자기 배치를 기억합니다. Layout은 작업 자리를 둘 이상 놓았을 때 생깁니다. 탭은 Layout이 아니라 작업 자리에 속하므로 Layout을 바꾸거나 풀어도 탭과 터미널은 멈추지 않습니다. Layout은 이 앱이 이 컴퓨터에 가진 저장소(localStorage)에 저장됩니다. 서버나 다른 컴퓨터로는 따라가지 않습니다.

이 페이지의 그림은 예시 데이터로 찍었습니다.

칸 나누기

섹션 제목: “칸 나누기”

한 탭의 본문(터미널이나 Session)을 둘로 나눠 나란히 봅니다.

  1. 나눌 터미널이나 Session 칸을 누릅니다.
  2. 키를 누릅니다.
동작 macOS Windows
오른쪽으로 나누기 ⌘D Ctrl+Shift+D
아래로 나누기 ⌘⇧D Alt+Shift+D
나눈 칸 닫기 ⌘W Ctrl+Shift+W

키 대신 칸 위쪽의 버튼(오른쪽으로 나누기, 아래로 나누기), 터미널 안의 오른쪽 클릭 메뉴, 탭 메뉴를 써도 됩니다. 나뉜 칸의 위쪽에는 나란히 보기에서 빼기와 나눈 칸 닫기 버튼도 있습니다. 둘 다 터미널과 Session은 멈추지 않습니다. 칸을 닫아도 세션은 계속 돕니다. 나란히 보기에서 빼기는 탭 메뉴에도 있습니다. 칸 사이 경계를 끌면 크기가 바뀝니다. 경계를 두 번 누르면 반반이 되고, 경계를 누른 뒤 화살표 키를 누르면 24px씩 움직입니다. 다른 칸으로는 Ctrl+Alt+방향키로 갑니다. 다음·이전 칸은 macOS ⌘⇧] / ⌘⇧[, Windows Ctrl+] / Ctrl+[입니다.

칸이 너무 작아지는 나누기는 되지 않고 이유를 알려 줍니다.

탭 그룹 나누기

섹션 제목: “탭 그룹 나누기”

한 탭을 새 탭 그룹으로 떼어 나란히 놓습니다.

  1. 탭 메뉴(… 또는 오른쪽 클릭)에서 오른쪽에 탭 그룹 나누기나 아래에 탭 그룹 나누기를 고릅니다.
  2. 탭 그룹 위 줄의 …(탭 그룹 메뉴)에도 같은 항목이 있습니다. 그 탭 그룹의 앞에 있는 탭을 새 탭 그룹으로 나눕니다.
  3. 탭을 끌어 탭 그룹 가장자리에 놓아도 됩니다. 놓을 자리에 새 탭 그룹 →, 옆에 보이기 → 같은 안내가 나옵니다.

탭 그룹 사이 경계도 끌어 크기를 바꾸고, 두 번 누르면 반반이 됩니다.

탭 그룹에서 할 수 있는 일은 탭 그룹 위 줄의 … 메뉴에 있습니다.

메뉴 하는 일
제목 정하기… 탭 그룹에 제목을 붙입니다. Enter로 저장, Esc로 취소, 비우면 Worktree 이름만 보입니다. 제목 지우기도 있습니다
다른 탭 그룹과 합치기 고른 탭 그룹에 이 탭 그룹의 탭을 합칩니다
모든 탭을 옮기기 고른 탭 그룹으로 탭을 모두 옮깁니다
탭 그룹 닫기 탭 그룹이 하나뿐이면 나오지 않습니다

탭을 다른 탭 그룹으로 보내는 탭 그룹으로 옮기기는 탭에 있습니다. 탭 그룹이 마지막 탭 하나만 가지면 그 탭은 새 탭 그룹으로 옮길 수 없습니다. 탭 그룹 위 줄에는 제목, 실행 위치 표시(이 컴퓨터에서 실행 또는 서버 이름), 프로젝트 이름 › Worktree 이름이 보입니다.

Layout 만들기

섹션 제목: “Layout 만들기”

화면에 Worktree가 있는 상태에서 다른 Worktree를 옆에 놓으면 Layout이 바로 만들어집니다. 저장 버튼은 없습니다.

방법 1. 탐색기 줄 메뉴

  1. 탐색기에서 옆에 놓을 Worktree 줄의 …를 누릅니다.
  2. 옆에 열기를 고릅니다. 지금 앞에 있는 탭 그룹의 오른쪽에 놓입니다. 이미 화면에 있는 Worktree에는 이 항목이 나오지 않습니다.

방법 2. 탭 그룹 메뉴

  1. 탭 그룹 위 줄의 …에서 **옆에 워크트리 열기…**를 고릅니다. 단축키 ⌘⇧\(Windows는 Ctrl+Shift+\)도 같습니다.
  2. 워크트리 찾기 목록에서 고릅니다. 이미 화면에 있는 것은 이미 이 화면에 있습니다로 막힙니다. 맞는 것이 없으면 “맞는 워크트리가 없습니다”가 나옵니다.

방법 3. 끌어 놓기

  1. 탐색기의 Worktree 줄을 누른 채 무대의 탭 그룹 가장자리로 끕니다.
  2. 놓을 자리에 안내가 나옵니다. 화면에 없는 Worktree는 옆에 놓이고, 이 탭 그룹을 이 워크트리로 바꾸기는 가운데에 놓으면 그 탭 그룹의 Worktree를 바꿉니다. 이미 화면에 있는 Worktree는 막힌 모양으로 나옵니다.

Layout에서 Worktree를 바꾸려면 탭 그룹 메뉴의 **워크트리 바꾸기…**를 고르거나 탭 그룹 위 줄에서 Worktree 이름을 누릅니다. Layout 안에서는 같은 Worktree를 두 번 놓을 수 없습니다.

Layout 목록

섹션 제목: “Layout 목록”

탐색기 아래에 Layout 목록이 있습니다. Layout이 하나도 없으면 목록 영역은 나오지 않습니다. 만들어지면 “저장된 Layout” 목록이 나타나고, 목록이 비어 있으면 “저장된 Layout이 없습니다. Explorer의 Worktree를 탭 그룹 가장자리로 끌어다 놓으면 만들어집니다.“라고 안내합니다.

  1. 목록의 줄을 눌러 그 Layout을 화면에 엽니다. 지금 화면에 있는 줄은 강조됩니다. 앞에 있던 Layout은 그대로 뒤에 남습니다.
  2. 줄에는 이름과 분할 모양의 작은 그림이 있고, 앞의 아홉 줄에는 오른쪽에 열기 단축키(⌘1⌘9, Windows는 Ctrl+1Ctrl+9)가 보입니다.
  3. 줄을 끌어 놓으면 순서가 바뀝니다.
  4. 단축키 표시를 끄려면 줄 메뉴의 단축키 표시 끄기를 고릅니다. 단축키 표시 켜기로 되돌립니다. 이 설정은 설정의 단축키 페이지와 같습니다.

이름을 붙이지 않으면 줄 이름은 들어 있는 Worktree 이름으로 정해집니다.

이름 바꾸기

  1. 줄 메뉴에서 이름 바꾸기를 고릅니다. 줄을 고르고 macOS는 Enter, Windows는 F2도 됩니다.
  2. Layout 이름에 적고 Enter를 누릅니다. Esc는 취소입니다. 이름은 64글자까지입니다. 비우면 이름 없는 상태로 돌아갑니다.

줄 메뉴에는 위로 이동, 아래로 이동, 탭 그룹 빼기, Layout 풀기도 있습니다. 다음·이전 Layout, 이름 바꾸기, 풀기, 풀기 되돌리기에도 단축키를 정할 수 있지만 처음에는 비어 있습니다.

탭 그룹 빼기와 Layout 풀기

섹션 제목: “탭 그룹 빼기와 Layout 풀기”
  • 탭 그룹 빼기: 줄 메뉴에서 Worktree를 고르면 그 Worktree의 탭 그룹이 Layout에서 빠집니다. 화면에 열려 있는 Layout에서는 탭 그룹 위 줄의 ×(Layout에서 빼기)나 탭 그룹 메뉴의 Layout에서 빼기도 됩니다. 이 탭 그룹만 보기는 그 Worktree 하나만 크게 엽니다.
  • 한 Layout에는 탭 그룹이 최소 둘 있어야 합니다. 하나만 남으면 그 Layout은 끝납니다.
  • Layout 풀기: 줄 메뉴에서 고르면 줄이 사라지고 “Layout을 풀었습니다: 이름”과 “탭과 터미널은 그대로 있습니다.“라는 알림이 나옵니다. 10초 안에 되돌리기를 누르면 돌아옵니다.
  • Layout에 들어 있던 Worktree를 삭제하면 그 Layout은 저절로 끝나고 “이름 Layout은 워크트리가 지워져 끝났습니다. 남은 탭은 그 워크트리의 화면에 있습니다.“라고 알려 줍니다.

한도

섹션 제목: “한도”
한도 값
저장할 수 있는 Layout 수 256개
Layout 하나의 저장 크기 64 KiB
탭 그룹을 나눌 수 있는 깊이 32단계
탭 그룹 안에 남아야 하는 최소 크기 터미널 40 × 8칸, 파일과 웹 220 × 70픽셀

한도에 닿으면 하지 않고 이유를 알려 줍니다. 예: “Layout이 256개가 넘어 더 만들 수 없습니다. 안 쓰는 Layout을 풀고 다시 하세요.”

이 화면의 말

섹션 제목: “이 화면의 말”

용어 페이지에서 Layout, 탭 그룹, 칸, 나누기를 설명합니다.

잘 안 될 때

섹션 제목: “잘 안 될 때”
보이는 것 하면 되는 것
“탭 그룹이 작아서 나눌 수 없습니다. 터미널은 40 × 8칸, 파일과 웹은 220 × 70픽셀이 남아야 합니다.” 창이나 탭 그룹을 넓히거나 다른 탭 그룹을 줄인 뒤 다시 나눕니다
“이미 이 Layout에 있는 워크트리입니다. 다른 워크트리를 고르세요.” 다른 Worktree를 고릅니다
“이 Layout이 저장 한도(64 KiB)를 넘어” 탭 그룹이나 탭을 줄입니다
“이 탭 그룹의 마지막 탭은 새 탭 그룹으로 옮길 수 없습니다. 다른 탭을 먼저 여세요.” 탭을 하나 더 연 뒤 옮깁니다
“Layout 단축키 표시를 저장하지 못했습니다.” 표시는 바뀐 대로 쓸 수 있습니다. 저장소 접근을 확인한 뒤 다시 바꿉니다
목록의 Layout이 사라졌습니다 마지막 탭 그룹이 빠졌거나 Worktree가 삭제되었을 수 있습니다. 위 알림에서 되돌리기를 시도합니다
