설정

설정은 Lyra의 연결과 동작을 바꾸고 확인하는 화면입니다. 서버를 잇고, 에이전트를 고르고, 화면 모양과 단축키를 바꾸고, 앱 버전과 문제 기록을 봅니다. 왼쪽 막대의 설정을 눌러 엽니다.

화면은 왼쪽 목차와 오른쪽 내용으로 나뉩니다. 목차에서 항목을 고르면 오른쪽이 그 항목으로 바뀝니다. 대부분의 설정은 고르는 즉시 저장됩니다.

이 페이지의 그림은 예시 데이터로 찍었습니다.

목차에서 항목을 찾으려면

섹션 제목: “목차에서 항목을 찾으려면”
  1. 목차 맨 위 설정 검색 칸에 글자를 넣습니다. 항목 이름이나 설명에 그 글자가 든 항목만 남습니다. 단축키는 명령 이름과 키로도 찾아집니다.
  2. 맞는 항목이 없으면 「일치하는 설정이 없습니다.」가 나옵니다.
  3. 항목을 누르면 오른쪽에 그 내용이 나옵니다.
  4. 앞뒤로 가기를 누르면 직전에 보던 항목으로 돌아옵니다.

목차는 다섯 묶음이고, 항목마다 한 페이지가 있습니다.

묶음 항목
연결 WSL · 원격 · 에이전트 · 이슈 연결
localhost 일반 · 모양 · 단축키 · 에이전트 스킬 · 오케스트레이션
도구 시리얼
사용 토큰 프로파일링
정보 앱 · 문제 기록
  • WSL은 Windows 컴퓨터에서만 목차에 나옵니다. macOS에서는 보이지 않습니다.
  • 묶음 이름이 localhost인 곳은 이 컴퓨터에만 해당하는 설정입니다.
  • 시리얼은 이 버전에서 잠겨 있어 스위치를 켤 수 없습니다. 자세한 것은 시리얼에 있습니다.
  • 에이전트 스킬 옆에 점이 있으면 고칠 스킬이 있다는 뜻입니다. 점의 이름은 「에이전트 스킬에 확인할 항목 있음」입니다.

페이지 안내

섹션 제목: “페이지 안내”
페이지 다루는 것
WSL Windows의 WSL을 서버처럼 잇고, 데이터와 연결을 정리하기

에이전트 기계마다 쓸 수 있는 에이전트와 프로필, 캐시 타이머
이슈 연결 이슈 서비스와 연결을 만들고 지우기
일반 링크 열기, 카드 보기, 작업 자리 삭제 확인 같은 기본 동작
모양 테마, 팔레트, 글자 크기, 터미널 모양
단축키 명령마다 쓰는 키 바꾸기
에이전트 스킬 Lyra 스킬이 컴퓨터마다 최신인지 보고 고치기
오케스트레이션 여러 세션에 일을 맡길 때의 규칙
시리얼 시리얼 포트 기능 켜고 끄기
토큰 프로파일링 토큰 사용량과 캐시 적중률 살펴보기
앱 앱 버전 확인, 업데이트, 되돌리기, 기록
문제 기록 오류와 경고 모아 보기, 기술 정보 복사

이 화면의 말

섹션 제목: “이 화면의 말”

용어에서 각 말의 뜻을 봅니다.

말 이 화면에서
서버 연결해 쓰는 다른 컴퓨터. 서버와 Host에서 설명합니다
프로필 에이전트를 어떻게 시작할지 정한 묶음. 프로필과 에이전트에서 설명합니다
localhost 이 컴퓨터

잘 안 될 때

섹션 제목: “잘 안 될 때”
보이는 것 할 일
목차에서 항목이 보이지 않음 설정 검색의 글자를 지웁니다
항목을 눌러도 고쳐지지 않음 쓰기가 막힌 상태입니다. 설정을 읽을 수만 있습니다
저장하지 못했다는 안내 항목 페이지의 「잘 안 될 때」를 봅니다. 계속되면 문제 기록에서 기술 정보 복사로 알립니다
