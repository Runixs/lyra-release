에이전트

에이전트는 컴퓨터마다 Claude Code, Codex, OpenCode 같은 에이전트(코드를 읽고 쓰며 일하는 프로그램)가 어디에 설치되어 있는지 보여 주는 곳입니다. 각 에이전트 아래에는 프로필(어느 에이전트를 어떤 설정으로 실행할지 적어 둔 것)이 있습니다. 프로필이 무엇인지는 프로필과 에이전트에 있습니다.

화면 왼쪽은 기계 목록이고, 오른쪽은 고른 기계 하나의 칸입니다. 목록에는 이 컴퓨터(localhost), 더한 WSL 배포판, 등록한 서버가 이 순서로 나옵니다. 줄마다 이름, WSL이나 SSH 표시, 상태와 찾은 에이전트 수(「연결됨 · 2개」)가 있습니다. 상태는 서버는 연결됨 · 연결 끊김 · 확인 전, WSL 배포판은 켜짐 · 꺼짐 · 켜는 중입니다.

오른쪽 칸은 두 부분입니다.

  • 설치됨: 그 기계에서 찾은 에이전트가 한 줄씩 나오고, 그 에이전트에서 복사한 프로필이 바로 아래에 들여 쓰여 나옵니다. 줄은 이름, 버전, 사용 스위치, ⋯ 단추입니다.
  • 지원 가능: Lyra가 지원하지만 그 기계에 없는 에이전트입니다. 줄마다 설치 안 됨(또는 경로에 없음)과 설치 방법 단추가 있습니다.

이 페이지의 그림은 예시 데이터로 찍었습니다.

기계를 고르고 에이전트를 다시 찾으려면

섹션 제목: “기계를 고르고 에이전트를 다시 찾으려면”
  1. 왼쪽 기계 목록에서 기계를 누릅니다.
  2. 오른쪽 칸 머리의 지금 확인을 누릅니다. 단추의 이름은 「…의 에이전트 런타임 지금 확인」입니다.
  3. 찾는 동안 단추에 읽는 중 표시가 나옵니다. 끝나면 줄이 새로 바뀝니다.
  • 연결되지 않은 서버에는 지금 확인 대신 연결이, 꺼진 WSL 배포판에는 켜기가 나옵니다. 누르면 원격이나 WSL에서 누른 것과 같이 연결하거나 켠 뒤 에이전트를 찾습니다. 실패하면 칸 머리 아래에 이유가 나옵니다.
  • 등록만 하고 한 번도 연결하지 않은 서버는 상태가 확인 안 됨이고, 「서버 “…”에 아직 연결한 적이 없어 에이전트를 읽지 않았습니다. [연결]을 누르면 읽습니다.」가 나옵니다.
  • 연결되지 않았거나 꺼진 기계의 줄은 흐리게 잠깁니다. 스위치와 **⋯**를 쓸 수 없고, 이름을 누르면 마지막으로 본 내용만 나옵니다.
  • 이 기계에서 아무것도 못 찾으면 설치됨 아래에 「감지된 에이전트가 없습니다.」라고 나옵니다.
  • 찾지 못했을 때는 칸 머리의 상태가 확인 안 됨이 됩니다. 말을 누르면 이유가 나옵니다. 서버이면 원격 열기 단추가 함께 있어 원격으로 갑니다.
  • 버전 확인이 시간 안에 끝나지 않았으면 그 에이전트 줄을 펼친 자리에 「…버전 확인이 …초 안에 끝나지 않았습니다. [지금 확인]을 눌러 다시 확인하세요.」가 나옵니다.
  • OpenCode가 2.0.0보다 낮으면 그 줄 아래에 「…의 OpenCode … 버전(…)이 Lyra에 필요한 버전(2.0.0 이상)보다 낮아 Lyra가 이 OpenCode로 세션을 열 수 없습니다. 그 컴퓨터에서 opencode upgrade를 실행한 뒤 [지금 확인]을 누르세요.」가 나옵니다.

에이전트 줄의 내용을 보려면

섹션 제목: “에이전트 줄의 내용을 보려면”

에이전트나 프로필의 이름을 누르면 아래에 펼쳐집니다. 다시 누르면 접힙니다.

항목 뜻
실행 명령 프로필이 실행하는 명령
실행 전 명령 있으면 설정됨, 없으면 없음
경로 찾은 실행 파일의 경로
확인 확인됨, 경로에 없음, 확인 안 됨, 고쳐야 함, 확인 전 가운데 하나

기계의 정보를 보려면

섹션 제목: “기계의 정보를 보려면”

칸 머리의 기계 이름을 눌러 펼칩니다.

항목 뜻
연결 이 컴퓨터에서는 localhost, 서버에서는 SSH 호스트·포트·사용자
OS 기계의 운영체제
Lyra 이 컴퓨터에서만 나옵니다. 앱 버전
lyra-daemon · 프로토콜 그 기계에서 도는 lyra-daemon의 버전과 프로토콜

값을 모르면 확인 전이라고 나옵니다. 서버를 펼치면 서버의 lyra-daemon 기록도 함께 나옵니다. 뜻은 원격에 있습니다.

이 컴퓨터의 lyra-daemon이 앱과 버전이 다르면 앱 버전(…)과 다름 표시와 lyra-daemon 업데이트 단추가 나옵니다. 단추를 누르면 「이 컴퓨터의 lyra-daemon을 다시 시작할까요?」 창이 실행 중인 버전, 앱에 포함된 버전, 종료될 세션과 터미널의 수를 보여 줍니다. lyra-daemon 다시 시작을 누르면 이 컴퓨터의 세션과 독립 터미널이 종료됩니다. 그만두려면 취소를 누릅니다.

프로필을 켜고 끄려면

섹션 제목: “프로필을 켜고 끄려면”

에이전트와 프로필 줄마다 버전 오른쪽에 스위치가 있습니다. 스위치의 이름은 「Claude Code 사용」처럼 「이름 사용」입니다. 스위치는 그 기계의 그 프로필만 바꿉니다.

  1. 스위치를 눌러 켜거나 끕니다.
  2. 바뀐 값이 바로 저장됩니다.
  • 잠긴 기계의 줄은 스위치를 쓸 수 없습니다.
  • 저장하지 못하면 목록 아래에 이유가 나옵니다.

프로필을 고치려면

섹션 제목: “프로필을 고치려면”
  1. 에이전트나 프로필 줄 끝의 ⋯(이름은 「… 더 보기」)를 눌러 **프로필 편집…**을 고릅니다. 프로필 편집 창이 열립니다.
  2. 설정 탭에서 칸을 고칩니다.
  3. 저장을 누릅니다. 저장하면 창이 닫힙니다.

창 제목 옆에는 어느 컴퓨터의 프로필인지 나옵니다. 입력을 바꾼 채 닫으려 하면 「저장하지 않은 입력이 있습니다」가 나오고, 머무르기나 버리기를 고릅니다.

칸 뜻
프로필 이름 프로필 이름. 에이전트의 기본 프로필은 바꿀 수 없고, 복사해 만든 프로필은 바꿀 수 있습니다
에이전트 어느 에이전트의 프로필인지
아이콘 · 색상 프로필을 알아보게 하는 그림과 색. 색은 에이전트 기본값, 파랑, 보라, 청록, 초록, 호박색, 장미색 가운데 고릅니다
모델 이름 (선택) 적으면 모델 목록을 조회하지 않고 그 이름을 씁니다. 비워 두면 자동으로 고릅니다(자동 조회)
실행 파일 (절대 경로) 에이전트 실행 파일의 전체 경로
Claude 설정 파일 Claude Code 프로필에서만 나옵니다. 실행 전에 파일이 있는지만 확인하고 내용은 읽지 않습니다
실행 전 명령 에이전트를 시작하기 직전에 그 컴퓨터에서 실행하는 명령. 실패하거나 30초 안에 끝나지 않으면 세션을 열지 않습니다. 비밀번호나 토큰은 적지 말고 파일이나 키체인에서 읽습니다
기본 인수 인수를 줄마다 하나씩 적습니다
권한 모드 인수 펼치면 권한 제한 없음 모드 추가 인수를 고치고, **권한 제한 모드 추가 인수 (읽기 전용)**를 읽을 수 있습니다
  • Windows 컴퓨터의 프로필에서는 실행 전 명령 칸이 잠기고 「Windows에서는 실행 전 명령을 사용할 수 없어 이 칸을 잠갔습니다. macOS 또는 Linux 실행 기기에서 설정하세요.」라고 나옵니다.
  • 실행 전 명령이 있는지는 줄을 펼친 내용의 실행 전 명령(설정됨 또는 없음)에서 봅니다.
  • 기본 명령으로 되돌리기(복사한 프로필은 원본 프로필의 명령으로 되돌리기)를 누르면 이 프로필이 기본 명령을 따르도록 바로 저장합니다.
  • 저장할 때 칸이 맞지 않으면 어느 칸이 문제인지 알려 주고 그 칸에 커서가 갑니다. 예를 들어 실행 파일이 올바른 전체 경로가 아니면 「실행 파일을 확인하세요. 올바른 절대 경로가 필요합니다.」, 인수가 맞지 않으면 「명령 인수를 확인하세요. {model}이 정확히 한 번 필요합니다. …」라고 나옵니다.
  • 아래쪽 줄에는 마지막 테스트 결과가 나옵니다. 테스트하지 않았어도 저장할 수 있습니다.

프로필을 추가하려면

섹션 제목: “프로필을 추가하려면”

기본 프로필을 복사해서 새 프로필을 만듭니다. 같은 에이전트를 다른 모델이나 다른 실행 명령으로 쓰고 싶을 때 씁니다.

  1. 칸 머리의 에이전트/프로필 추가를 누르고 **프로필 추가…**를 고릅니다. 복사할 줄의 **⋯**에서 **프로필 복사…**를 골라도 됩니다. 이때는 그 에이전트가 골라진 채 열립니다.
  2. 프로필 추가 창에서 프로필 이름을 적고 에이전트에서 어느 에이전트를 복사할지 고릅니다.
  3. 필요한 칸을 고치고 저장을 누릅니다.
  • 그 기계에서 확인된 에이전트가 없거나 기계가 잠겨 있으면 **프로필 추가…**가 눌리지 않습니다. 확인되지 않은 에이전트 줄의 **프로필 복사…**도 눌리지 않습니다.
  • 프로필은 만들었지만 실행 설정을 저장하지 못하면 「…프로필은 만들었지만 실행 설정을 저장하지 못했습니다. 이 창에서 다시 저장하거나 프로필을 다시 열어 설정을 마치세요.」라고 나옵니다.

실행 명령을 테스트하려면

섹션 제목: “실행 명령을 테스트하려면”

저장하기 전에 입력한 값 그대로 시험해 볼 수 있습니다.

  1. 프로필 편집 창에서 테스트 탭을 엽니다.
  2. 테스트 시작을 누릅니다. 다시 하려면 다시 테스트, 끝내려면 테스트 종료를 누릅니다.
  3. 세 단계의 상태를 봅니다. 실행 전 명령, 에이전트 시작, 모델 확인 순서입니다.
단계 상태 뜻
대기 아직 하지 않았습니다
진행 중 하고 있습니다

프로필을 지우려면

섹션 제목: “프로필을 지우려면”

복사해서 만든 프로필만 지울 수 있습니다. 기본 프로필의 **⋯**에는 삭제가 없습니다.

  1. 복사한 프로필 줄의 **⋯**에서 삭제를 고릅니다. 프로필 창을 열어 아래쪽의 지우기를 눌러도 됩니다.
  2. 프로필 지우기 창에서 지우기를 누릅니다. 그만두려면 취소를 누릅니다.

지운 프로필을 다시 쓰려면 프로필을 새로 추가해야 합니다.

에이전트를 설치하려면

섹션 제목: “에이전트를 설치하려면”
  1. 칸 머리의 에이전트/프로필 추가를 누르고 **에이전트 설치…**를 고릅니다. 지원 가능의 에이전트 줄에 있는 설치 방법을 눌러도 같은 창이 열립니다.
  2. 창에 Claude Code, Codex, OpenCode가 한 줄씩 있습니다. 설치되어 있으면 버전이, 아니면 설치 안 됨이 나옵니다.
  3. 설치할 에이전트 줄의 설치 방법을 누릅니다. 설치 명령이 나오면 복사 단추로 복사해 그 컴퓨터의 터미널에서 실행합니다. 명령이 없는 경우에는 공식 안내의 열기를 눌러 안내 페이지를 엽니다.
  4. 설치한 뒤 같은 줄의 지금 확인을 눌러 다시 찾습니다.

명령 위에는 어디서 실행하는 명령인지(PowerShell, macOS 터미널, Linux 터미널)와 컴퓨터 이름이 적혀 있습니다.

캐시 타이머를 켜고 끄려면

섹션 제목: “캐시 타이머를 켜고 끄려면”

프롬프트 캐시(에이전트가 대화의 앞부분을 잠시 기억해 두어 다음 메시지 비용을 줄이는 것)가 남은 시간을 프로젝트의 Session 줄에 타이머로 보여 줄지 정합니다. Claude Code와 그 프로필에만 있습니다.

  1. Claude Code나 그 프로필 줄의 **⋯**를 엽니다.
  2. 캐시 타이머를 눌러 켜거나 끕니다. 바로 저장됩니다.
  • 처음 값은 켜짐입니다. 끄면 그 프로필로 연 Session 줄에 타이머가 나오지 않습니다.
  • 캐시가 유지되는 시간은 Claude Code가 정합니다. Lyra는 시간을 따로 청하지 않고, 타이머는 Claude Code가 기록한 값으로 셉니다.
  • 터미널에서 직접 claude를 실행한 줄은 그 기계의 Claude Code 기본 프로필의 스위치를 따릅니다.
  • Codex와 OpenCode는 유지 시간을 기록하지 않아 타이머도 스위치도 없습니다.
  • 저장하지 못하면 그 줄 아래에 이유가 나옵니다.

이 화면의 말

섹션 제목: “이 화면의 말”

용어에서 각 말의 뜻을 봅니다.

말 이 화면에서

lyra-daemon 컴퓨터마다 에이전트를 돌리는 Lyra의 실행 엔진

잘 안 될 때

섹션 제목: “잘 안 될 때”
보이는 것 할 일
「감지된 에이전트가 없습니다.」 에이전트를 설치한 뒤 지금 확인을 누릅니다. 위 에이전트를 설치하려면을 봅니다
칸 머리의 확인 안 됨 말을 눌러 이유를 읽고 다시 찾습니다. 서버면 원격에서 연결을 확인합니다
줄이 흐리고 스위치와 **⋯**가 잠김 기계가 연결되지 않았거나 꺼졌습니다. 칸 머리의 연결이나 켜기를 누릅니다
에이전트가 지원 가능에 있음 그 기계에서 찾지 못한 것입니다. 설치하거나 경로를 확인한 뒤 다시 찾습니다
실행 전 명령 칸이 잠김 Windows 컴퓨터의 프로필입니다. macOS나 Linux 컴퓨터에서 설정합니다
저장할 때 어느 칸이 문제라는 안내 커서가 간 칸을 고칩니다
에이전트가 바로 끝남 문제 해결을 봅니다
