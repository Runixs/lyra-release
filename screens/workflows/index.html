워크플로

워크플로는 되풀이되는 일을 단계로 적어 둔 설계도입니다. 요리 레시피와 비슷합니다. 한 번 적어 두면 같은 일을 몇 번이고 돌릴 수 있습니다. 워크플로를 한 번 돌린 것이 실행이고, 설계도 속의 한 단계가 노드(그림 속 상자 하나)입니다.

노드 종류는 둘입니다.

노드 하는 일
Trigger 실행이 시작되는 조건입니다. 사람이 직접 시작하거나, Jira · GitHub에서 이슈가 나에게 배정될 때 시작합니다
Agent 에이전트(Claude Code, Codex, OpenCode)가 프롬프트(할 일을 적은 글)대로 일하는 단계입니다

이 화면은 목록입니다. 목록에서 워크플로를 켜고 끄고, 실행하고, 최근 실행을 엽니다. 워크플로를 만들고 고치는 일은 편집, 돌고 있는 실행을 지켜보는 일은 실행 화면에 있습니다.

워크플로 화면은 왼쪽 막대의 워크플로를 눌러 엽니다. 왼쪽에는 워크플로 목록(제목 「워크플로」와 「시작 조건에 따라 단계를 실행하고 진행 상황과 결과를 확인합니다.」)이, 오른쪽에는 최근 실행이 있습니다.

예시 데이터로 찍은 화면입니다.

목록을 읽으려면

섹션 제목: “목록을 읽으려면”

한 줄에는 이런 것이 보입니다.

보이는 것 뜻
이름 누르면 저장된 워크플로가 열립니다 (아래)
상태 표시와 시작 까닭 지금 돌고 있는 실행입니다. 돌고 있는 것이 없으면 마지막 실행 하나를, 실행한 적이 없으면 「실행 없음」을 보입니다
시작 조건 직접 실행, 또는 연결 이름 · 프로젝트 키 · 나에게 배정. 실행이 만들어질 Lyra 프로젝트가 정해져 있으면 → 프로젝트 이름이 붙습니다
v3 버전입니다. 저장할 때마다 오릅니다
켜기 스위치 옆에 「켜짐」 또는 「꺼짐」이 적힙니다
지금 실행, 할당 확인, 편집 아래에서 설명합니다
  • 상태 표시는 Working, Waiting, Idle, Done처럼 영어 그대로 적히고, 그 밖에 시작 전, 정지됨이 있습니다. 상태 표시의 뜻은 실행 화면에 있습니다.
  • 시작 까닭은 「ABC-123 이(가) 나에게 배정됨 · 시각」 또는 「직접 실행 · 시각」 모양입니다.
  • 줄의 상태 표시를 누르면 그 실행의 실행 화면이 열립니다.
  • 시작 조건이 가리키는 연결이 설정에 없으면 줄에 「연결 … 이(가) 없습니다. 설정 → 이슈 연결에서 추가하거나, 편집에서 다른 연결을 고르세요.」라는 경고가 붙습니다. 연결은 설정에서 만듭니다.
  • 아직 워크플로가 없으면 「아직 워크플로가 없습니다. 새 워크플로를 만들어 보세요.」가 나옵니다.
  • 읽는 동안에는 「읽는 중…」이 보입니다.

돌고 있는 실행이 있으면 목록이 5초마다 저절로 새로 읽힙니다. 돌고 있는 것이 없으면 이 화면에 들어올 때와 데이터가 바뀌었다고 알려 올 때만 읽습니다.

오른쪽 최근 실행에는 가장 최근 실행 20개가 나옵니다. 줄마다 워크플로 이름, 상태 표시, 시작 까닭이 있고, 누르면 그 실행이 열립니다. 실행이 하나도 없으면 「아직 실행이 없습니다.」가 나옵니다.

워크플로를 켜고 끄려면

섹션 제목: “워크플로를 켜고 끄려면”
  1. 줄의 스위치(이름은 「이름 켜기」)를 누릅니다.
  2. 옆의 글자가 「켜짐」 또는 「꺼짐」으로 바뀝니다.

켜 둔 워크플로는 시작 조건이 Jira나 GitHub일 때 이슈가 나에게 배정되면 저절로 실행을 시작합니다. 직접 실행 조건의 워크플로는 켜 두어도 저절로 시작하지 않고, 지금 실행으로만 돌립니다. 같은 이슈에 맞는 켜진 워크플로가 여럿이면 워크플로마다 실행이 하나씩 생깁니다.

스위치는 바꾸는 동안, 그리고 쓰기가 막힌 상태(앱이 엔진과 아직 이어지지 않았을 때)에서는 눌리지 않습니다.

지금 실행하려면

섹션 제목: “지금 실행하려면”
  1. 줄의 지금 실행을 누릅니다. 저장된 워크플로 화면 위쪽의 같은 단추도 됩니다.
  2. 열린 창에서 입력하고 지금 실행을 누릅니다. 자세한 단계는 지금 실행에 있습니다.

새로 배정된 이슈를 지금 확인하려면

섹션 제목: “새로 배정된 이슈를 지금 확인하려면”

시작 조건이 Jira나 GitHub인 워크플로 줄에만 할당 확인이 있습니다.

  1. 할당 확인을 누릅니다. 단추에 마우스를 올리면 「새로 배정된 이슈가 있으면 연결된 Workflow가 시작될 수 있습니다.」라고 나옵니다.
  2. 새로 배정된 이슈가 있으면 켜진 워크플로가 실행을 시작합니다.

시작 조건의 연결이 설정에 없으면 단추가 눌리지 않습니다.

저장된 워크플로를 열려면

섹션 제목: “저장된 워크플로를 열려면”
  1. 줄의 이름을 누릅니다.
  2. 그래프가 보이고, 오른쪽 옆판에 두 탭이 있습니다.
탭 보이는 것
정의 워크플로 파일의 글입니다. 그래프의 노드를 누르면 이 탭이 열립니다
최근 실행 이 워크플로의 실행 목록입니다. 줄을 누르면 그 실행이 열립니다

위쪽에는 목록(목록으로 돌아가기), 이름과 버전 v3, 연결 표시, 시작 조건, 지금 실행, 편집이 있습니다. 여기서는 상태 표시와 노드 메뉴가 없습니다. 보기만 하는 그림입니다.

그래프 왼쪽 아래의 도구로 축소, 확대, 그래프 전체 보기를 하고, 왼쪽 → 오른쪽 · 위 → 아래로 그래프 방향을 바꿉니다. 방향은 워크플로마다 기억합니다. 배치 엔진을 이 창에서 띄우지 못하면 「그래프를 배치하지 못했습니다…」라는 안내가 나옵니다.

옆판은 그래프와의 경계(「그래프와 옆판 사이 너비 조절」)를 끌어 너비를 바꿉니다. 너비는 창이 열려 있는 동안 기억됩니다.

새 워크플로를 만들려면

섹션 제목: “새 워크플로를 만들려면”
  1. 목록 오른쪽 위의 새 워크플로를 누릅니다.
  2. 편집 화면이 새 워크플로로 열립니다.

쓰기가 막힌 상태에서는 새 워크플로가 눌리지 않습니다.

이 화면의 말

섹션 제목: “이 화면의 말”

용어에서 각 말의 뜻을 봅니다.

말 이 화면에서
워크플로 목록의 한 줄, 단계로 적어 둔 설계도
실행 워크플로를 한 번 돌린 것
노드 설계도 속의 한 단계. Trigger와 Agent
시작 조건 직접 실행 또는 나에게 배정
v3 저장할 때마다 오르는 버전
최근 실행 오른쪽에 모인 가장 최근 실행들
Working · Waiting · Idle · Done 실행과 노드의 상태 표시

잘 안 될 때

섹션 제목: “잘 안 될 때”
보이는 것 할 일
목록 위에 읽지 못했다는 문장 화면을 나갔다가 다시 엽니다. 문장에 이유가 적혀 있습니다. 계속되면 문제 해결을 봅니다
줄에 「연결 … 이(가) 없습니다.」 설정에서 연결을 만들거나, 편집에서 시작 조건의 연결을 다른 것으로 고릅니다
할당 확인이 눌리지 않음 시작 조건의 연결이 설정에 있는지 봅니다
스위치와 지금 실행이 눌리지 않음 쓰기가 막힌 상태입니다. 앱이 엔진과 이어질 때까지 기다립니다

개발자용: Workflows, Workflows details.
