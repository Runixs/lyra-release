실행 화면

실행 화면은 워크플로를 한 번 돌린 실행 하나를 지켜보는 화면입니다. 어느 노드가 일하는 중이고, 어디서 실패했고, 에이전트가 무엇을 남겼는지 한곳에서 봅니다.

실행 화면은 이런 곳에서 엽니다.

  • 목록의 줄에 있는 상태 표시, 또는 오른쪽 최근 실행의 줄
  • 저장된 워크플로 화면의 최근 실행 탭
  • 지금 실행으로 실행을 시작한 직후
  • 받은 요청의 실행 열기
  • 이슈에서 Workflow로 시작한 직후

실행이 돌고 있는 동안에는 화면이 2초마다 저절로 새로 읽힙니다. 이 화면이 보이지 않는 동안에는 읽지 않습니다.

예시 데이터로 찍은 화면입니다.

화면의 짜임

섹션 제목: “화면의 짜임”
자리 내용
위쪽 실행 머리: 이슈 키 또는 실행 이름, 상태 표시, 실행 정보, 돌고 있으면 실행 정지
가운데 메인 영역. 맨 앞의 그래프 탭과, 연 파일·산출물·작업 자리 탭이 있습니다
그래프 위 띠: 내 답을 기다리는 일과 끝난 실행의 결과
아래 세션 패널. 노드의 에이전트 터미널이 보입니다
오른쪽 옆판 세 탭: 실행 기록, 근거, 노드

상태 표시

섹션 제목: “상태 표시”

실행과 노드에는 상태 표시가 붙습니다. 표시의 뜻은 이렇습니다.

표시 뜻
시작 전 아직 시작하지 않았습니다. 이유가 붙을 때가 있습니다: 「시작 전 · 앞 단계 기다림」, 「시작 전 · 시작 대기」, 「시작 전 · 빈 Worker 자리」, 「시작 전 · 같은 폴더」
시작 중 · 확인 중 엔진이 단계를 시작하는 중이거나, 세션의 상태를 확인하는 중입니다
Working 에이전트가 일하는 중입니다
Waiting 사람을 기다립니다. 이유가 붙습니다: 「Waiting · 승인 필요」, 「Waiting · 결정 필요」, 「Waiting · 사람 확인 필요」, 「Waiting · 답 필요」
Idle 세션이 아직 첫 턴을 시작하지 않았습니다
Interrupted 사람이 멈춘 턴입니다
Done 끝났습니다
Failed 실패했습니다
정지됨 멈췄습니다
건너뜀 이번에는 하지 않았습니다 (노드만)
Unknown 상태를 확인하지 못했습니다

표시는 색만으로 알리지 않고 항상 글자가 함께 붙습니다.

머리를 읽고 실행을 멈추려면

섹션 제목: “머리를 읽고 실행을 멈추려면”
  1. 위쪽 줄에서 이슈 키(이슈가 없으면 실행 이름)와 상태 표시를 읽습니다. 이슈 키를 누르면 그 이슈 페이지가 브라우저에서 열립니다.
  2. 아래 줄에서 워크플로 이름, 연결 표시, 시작 까닭(「나에게 배정되어 시작」 또는 「직접 실행」), 걸린 시간을 읽습니다.
  3. 실행 정보를 누르면 창에 이슈, 워크플로, 실행 ID(ID 복사 단추가 있습니다), 연결, 시작, 시작 시각이 전부 나옵니다. 모르는 값은 「확인 불가」입니다.
  4. 돌고 있는 실행을 멈추려면 실행 정지를 누릅니다. 쓰기가 막힌 상태에서는 눌리지 않습니다.

실행을 멈추면 상태 표시가 정지됨으로 바뀝니다. 멈추지 못하면 머리 아래에 이유가 나옵니다.

실행을 새로 읽지 못하면 머리에 「…의 최신 정보를 읽지 못했습니다. 위의 상태와 정보는 마지막으로 읽은 것입니다.」가 나오고, 상태 표시는 「마지막 확인 · Done」처럼 바뀝니다. 문제 기록 열기를 누르면 설정의 문제 기록으로 갑니다. 이때는 받은 요청으로 가는 단추도 눌리지 않습니다.

그래프를 읽으려면

섹션 제목: “그래프를 읽으려면”

그래프는 노드가 선으로 이어진 그림입니다. 노드 카드에는 이름, 종류, 상태 표시가 있고, 아래에 Trigger는 이슈 키, 나머지는 걸린 시간이 붙습니다. 산출물이 있으면 개수 표시가 붙습니다. 마지막 노드들 뒤에는 끝 표시가 있습니다.

  • 단계가 실패하면 앞 노드로 돌려보내는 선이 「실패하면 돌려보냄」과 「최대 N」 표시로 그려집니다. 승인 거부로 돌려보내는 선은 「거부」로 적힙니다.
  • 승인을 기다리는 단계 앞의 선에는 「승인 필요」가 붙습니다.
  • 노드를 누르거나 Enter를 누르면 옆판의 노드 탭이 열립니다.
  • 왼쪽 아래의 도구로 축소, 확대, 그래프 전체 보기와 방향 바꾸기(왼쪽 → 오른쪽 · 위 → 아래)를 합니다.

노드 메뉴를 쓰려면

섹션 제목: “노드 메뉴를 쓰려면”
  1. 노드 카드의 ⋯(마우스 오른쪽 단추나 Shift+F10도 됩니다)를 눌러 메뉴를 엽니다.
  2. 항목을 고릅니다.
항목 하는 일
상세 보기 옆판의 노드 탭을 엽니다
터미널 보기 세션 패널을 열고 그 노드의 터미널을 보입니다
산출물 보기 노드 탭의 산출물 목록으로 갑니다
근거 보기 노드 탭의 근거 부분으로 갑니다
작업 자리 보기 메인 영역에 그 노드의 작업 자리 탭을 엽니다
세션 ID 복사 세션 ID를 복사합니다

아직 없는 것은 이유와 함께 흐려집니다. 「이 노드에는 아직 세션이 없습니다」, 「이 노드에는 아직 산출물이 없습니다」, 「이 노드에는 근거 기록이 아직 없습니다」, 「이 노드에는 아직 작업 자리가 없습니다」입니다.

노드 하나를 자세히 보려면

섹션 제목: “노드 하나를 자세히 보려면”
  1. 노드를 누르거나 메뉴에서 상세 보기를 고릅니다.
  2. 옆판의 노드 · 이름 탭이 열립니다. 노드를 고르기 전에는 이 탭이 눌리지 않습니다.

탭 위쪽에는 노드 이름, 종류, 상태 표시와 상세 · 근거 두 부분 단추가 있습니다. 상세에는 이런 것이 나옵니다.

  • 세션 패널에서 보기: 세션 패널에서 이 노드의 터미널을 엽니다.
  • 상태에 이유가 있으면 한 줄로 보입니다.
  • 세션: 세션의 상태. 세션이 닫혔거나 턴이 끝났으면 시각이 붙습니다.
  • 시도: 「시도 2 / 3」 · 「돌려보내기 1번 남음」 · 「…시작」 · 걸린 시간.
  • 작업 자리: 이 노드가 일한 작업 자리의 이름.
  • 댓글: 에이전트 노드가 이슈에 남긴 댓글입니다. 있으면 남긴 댓글 열기, 없으면 「댓글 아직 없음」입니다.
  • 산출물: 노드가 남긴 결과물. 아래 산출물을 보세요.
  • 바뀐 파일: 작업 자리에서 바뀐 파일. 누르면 메인 영역에 비교 탭이 열립니다. 없으면 「바뀐 파일이 없습니다」입니다. 작업 자리 열기는 작업 자리 탭을 엽니다.
  • 시도 기록(시도가 둘 이상일 때): 시도마다 상태와 시작 시각이 나옵니다. 「(단계 이름) 단계가 실패해 다시 돌려보냈습니다.」, 「뒤 단계가 실패해 이 단계로 다시 돌려보냈습니다.」, 「승인이 거부되어 이 단계로 다시 돌아왔습니다.」처럼 왜 다시 했는지 알려 줍니다. 줄의 터미널 보기는 그 시도의 세션을 엽니다.

단계가 실패하면 같은 단계를 시도 2, 시도 3으로 다시 합니다.

세션 터미널을 보려면

섹션 제목: “세션 터미널을 보려면”

세션 패널은 그래프 아래에 있습니다. 접혀 있으면 「세션 패널」과 상태별 개수(예: 「1 Working」)가 한 줄로 보입니다.

  1. 위쪽 줄의 터미널 단추(「세션 패널 열기/닫기」)나 접힌 줄을 눌러 엽니다.
  2. 왼쪽 「세션」 목록에서 노드를 고릅니다. 줄마다 노드 이름, 에이전트, 세션 상태, 걸린 시간이 있고, 위아래 화살표와 Home, End로 옮깁니다.
  3. 오른쪽에 그 노드의 터미널이 나옵니다. 에이전트와 같은 세션이라 직접 입력할 수 있습니다.

패널 위쪽의 단추는 이렇습니다.

단추 하는 일
최대화 (「세션 패널 최대화/복원」) 패널을 키우거나 되돌립니다
닫기 (「세션 패널 닫기」) 패널을 접습니다
현재 시도 보기 지난 시도를 보고 있을 때 가장 새 시도로 돌아갑니다
  • 패널 위쪽 경계(「세션 패널 높이」)를 끌거나 화살표 키로 높이를 바꿉니다. 두 번 누르면 처음 높이로 돌아갑니다. 열림 여부와 높이는 창이 열려 있는 동안 기억됩니다.
  • 터미널 대신 이유가 나올 때가 있습니다. 「세션을 고르면 터미널이 여기에 표시됩니다」, 「이 노드는 에이전트를 실행하지 않아 세션이 없습니다」, 「세션이 시작되면 이곳에 터미널이 표시됩니다」, 「아직 시작 전입니다. … 완료 후 세션이 시작됩니다.」, 「… 단계의 시도 N에 세션 정보가 없어 터미널을 열 수 없습니다. 실행 기록에서 해당 시도의 상태를 확인해 주세요.」입니다.
  • 세션이 닫혔거나 실패했으면 다시 연결이 나옵니다. 처음 연 세션이 아니거나 실패하거나 닫는 중인 세션에는 세션 종료도 나옵니다.

실행 기록을 읽으려면

섹션 제목: “실행 기록을 읽으려면”

옆판의 실행 기록 탭은 처음에 열려 있습니다. 제목 「실행 기록」 아래에 「Lyra 엔진이 기록한 실행 상태 · 시간 순서」라고 적혀 있고, 일어난 일이 시각과 함께 한 줄씩 나옵니다.

  • 「ABC-123 이(가) 나에게 배정됨 — 실행 시작」, 「work — 시도 1 시작」, 「work — 시작 승인됨」, 「작업 자리 … 만듦」, 「work — Worker 시작」, 「ABC-123 에 댓글 남김」, 「실행 끝」 같은 문장입니다.
  • 끝난 일에는 상태 표시와 걸린 시간이 붙고, 이유가 있으면 아래에 한 줄로 붙습니다.
  • 승인이나 결정에 사람이 남긴 메모는 인용으로 나옵니다.
  • 댓글이나 이슈 주소가 있는 줄은 누르면 메인 영역에 그 주소의 탭이 열립니다.
  • 덜 중요한 줄은 「기록 N개 펼치기」로 묶여 있습니다. 순서는 바뀌지 않고 빠지는 줄도 없습니다.
  • 아직 없으면 「아직 기록 없음」입니다.

근거 기록을 읽으려면

섹션 제목: “근거 기록을 읽으려면”

워크플로의 단계는 일을 끝낼 때 근거를 남깁니다. “무엇을 고르고 왜 그랬는지”의 증거입니다. 사람이 승인하기 전에 이것을 보고 판단합니다.

  1. 옆판의 근거 탭을 누릅니다. 기록이 있으면 탭에 개수가 붙습니다.
  2. 노드와 쓴 쪽으로 걸러 봅니다. 「실행 전체」는 어느 노드에도 속하지 않은 기록입니다.
  3. 넓게 읽으려면 넓게 읽기를 누릅니다. 창이 열리고, 닫으면 앞서 보던 자리로 돌아갑니다.
  4. 기록 위쪽의 작성 정보를 펼치면 기록 ID, 기록한 세션이나 사람, 시도, 결정할 때 본 기록이 나옵니다.
기록 종류 뜻
선택 검토한 것 중 무엇을 골랐는지(고른 것)와 이유
가정 에이전트가 세운 가정
발견 일하다 알아낸 것
승인 사람의 승인이나 거부
면제 · 건너뜀 근거를 요구하는 검사를 면제했거나 건너뛴 기록. 무엇에 대한 것인지 「대상: …」으로 나옵니다

기록을 쓴 쪽은 「단계 work」처럼 단계 이름이 붙은 것, 「실행 Orchestrator」, 「사람」, 「Lyra」 중 하나로 적힙니다.

각 기록에는 근거가 붙고, 얼마나 믿을 수 있는지가 세 표시로 나뉩니다. 표시에 마우스를 올리면 뜻이 나옵니다.

표시 뜻
Lyra 가 확인 Lyra가 직접 돌려 보고 결과를 본 검사입니다
Lyra 보관 · 에이전트 작성 Lyra가 쓰인 그대로 보관한 파일이나 출력입니다. 내용은 에이전트가 썼습니다
에이전트 진술 에이전트만 말한 내용입니다. Lyra가 확인하거나 보관하지 않았습니다

세 번째 표시가 붙은 근거는 그대로 믿지 말고 필요하면 직접 확인하세요.

  • 근거 줄에는 파일, 출력, 검사, 명령과 종료 코드, 링크, 인용이 있습니다. 출력과 검사는 누르면 그 노드로 갑니다.
  • 파일 근거의 전체 보기는 64 KiB를 넘는 파일을 미리 보기까지만 보여 줍니다.
  • 단계가 근거를 남기지 않았고 건너뛴 이유도 적지 않았으면 「… 단계가 근거 기록을 남기지 않았고 건너뛴 이유도 적지 않았습니다.」가 나옵니다. 사람이 면제한 것은 「근거 기록은 사람이 면제했습니다. 통과한 것은 아닙니다.」로 구분해서 보입니다.
  • 목록을 확인하지 못하면 「이 실행의 근거 기록 목록을 확인하지 못했습니다. 기록이 없다는 뜻은 아닙니다.」, 일부만 읽었으면 「기록 N개와 근거 N개를 읽지 못했습니다. 읽을 수 있는 항목만 표시합니다.」가 나옵니다.
  • 기록이 없으면 「이 실행에는 근거 기록이 아직 없습니다.」입니다.

산출물을 열려면

섹션 제목: “산출물을 열려면”

산출물은 노드가 남기는 결과물입니다. 종류는 text, markdown, file, link, list입니다.

  1. 노드 탭의 산출물에서 줄을 누릅니다. 줄 이름은 「이름 — 그래프 옆 탭에서 엽니다」입니다.
  2. 메인 영역에 새 탭으로 열립니다. 이미 열려 있으면 그 탭으로 갑니다.
  3. 실행 전체의 산출물을 한꺼번에 보려면 노드 탭 아래의 실행 전체를 누릅니다. 「이 실행의 산출물」 탭이 열리고, 워크플로의 출력과 노드별 산출물이 묶여 나옵니다.

markdown 산출물에는 크게 보기, 작업 자리에 있는 file 산출물에는 파일에서 보기가 있습니다. 노드의 작업 자리 정보를 받지 못하면 「산출물 …의 작업 자리 정보를 받지 못해 …」라고 나오고 열리지 않습니다. 아직 없는 산출물은 「아직」, 끝난 시도가 남기지 않은 것은 「… · 빠짐 · 이유 없음」처럼 표시가 붙습니다.

메인 영역에 탭을 더하려면

섹션 제목: “메인 영역에 탭을 더하려면”
  1. 탭 줄 끝의 새 탭 단추를 누릅니다.
  2. 파일 열기… 또는 Open Browser를 고릅니다.
  3. 창에서 파일 경로나 주소를 적고 열기를 누릅니다.

파일과 이 컴퓨터 안에서만 열리는 주소는 노드의 작업 자리에서 열립니다. 창 설명에 「작업 자리: 노드 · 시도 N · 이름」이 적히고, 노드를 고르지 않았으면 「…작업 자리가 있는 노드를 먼저 골라주세요.」라고 나옵니다. 탭은 탭의 닫기 단추(「탭 닫기」)로 닫고, 맨 앞의 그래프 탭은 닫을 수 없습니다.

실행이 끝난 뒤 결과를 보려면

섹션 제목: “실행이 끝난 뒤 결과를 보려면”

실행이 Done으로 끝나면 그래프 위 띠에 「실행이 통과 상태로 끝났습니다.」가 나옵니다. 띠에는 에이전트가 이슈에 남긴 댓글 링크도 있습니다.

  • 하나면 남긴 댓글 열기, 여럿이면 「남긴 댓글 N개 보기」를 눌러 단계와 시도별 목록에서 고릅니다.
  • 없으면 「이 실행에서 확인된 댓글 링크가 없습니다.」입니다.
  • 실패나 정지의 이유도 같은 띠에 한 줄로 나옵니다.

실행이 만든 작업 자리를 지우려면

섹션 제목: “실행이 만든 작업 자리를 지우려면”

끝난 실행(돌고 있지 않은 실행) 중 작업 자리를 만든 것에는 옆판 아래에 작업 자리 관리가 나옵니다. 지우기 전에 무엇이 지워지는지 먼저 확인합니다.

  1. 작업 자리 관리를 펼칩니다.
  2. 삭제 전 확인을 누릅니다. 「삭제할 작업 자리와 커밋하지 않은 파일을 세는 중…」이 나옵니다.
  3. 창에 이 실행이 만든 작업 자리와 파일 수가 나옵니다. 커밋하지 않은 파일이 지워지는지, 파일이 이미 없는지, 세지 못했는지가 줄마다 적힙니다. 커밋이 있는 브랜치는 「브랜치 … 에 커밋이 있어 남겼습니다.」처럼 남깁니다.
  4. 지워도 되면 삭제를, 아니면 취소를 누릅니다. 삭제한 작업 자리는 되돌릴 수 없습니다.
  5. 한 번에 몇 개만 처리하므로 남은 것이 있으면 「나머지 작업 자리 N개는 이 삭제가 끝나면 다시 보여 드립니다.」가 나오고 확인과 삭제를 되풀이합니다.
  • 확인한 뒤 작업 자리가 바뀌었으면 아무것도 지우지 않고 새 목록을 다시 보여 줍니다.
  • Worker가 아직 그 작업 자리에서 일하고 있으면 「…삭제하지 못했습니다. 잠시 뒤 다시 삭제해 주세요.」 같은 문장이 나옵니다. 세션이 끝나거나 닫힌 뒤 다시 누릅니다.
  • 삭제하다 폴더가 남으면 화면 위쪽에 「작업 자리 … 을(를) 삭제하다 폴더 … 가 남았습니다. …」 경고가 계속 보입니다. 폴더를 직접 지운 뒤 다시 삭제를 누르면 확인합니다.
  • 이 실행이 만든 것인지 확인할 수 없는 작업 자리는 지우지 않고 남깁니다. 필요 없으면 프로젝트 화면에서 삭제합니다.

잘 안 될 때

섹션 제목: “잘 안 될 때”
보이는 것 할 일
「…의 최신 정보를 읽지 못했습니다.」 위의 상태는 마지막으로 읽은 것입니다. 문제 기록 열기로 이유를 찾아봅니다
터미널 대신 「세션 정보가 없어」 실행 기록과 노드 탭의 시도 기록에서 그 시도의 상태를 봅니다
