용어

이 페이지는

섹션 제목: “이 페이지는”

Lyra 화면에 나오는 낱말의 뜻을 한곳에 모았습니다. 낱말은 화면에 보이는 그대로 적었습니다. Working, Waiting처럼 영어로 보이는 말은 영어로 적었습니다. 낱말마다 그 말이 나오는 화면으로 가는 링크가 있습니다.

다른 페이지에서 모르는 말을 만나면 그 말의 링크를 눌러 이곳으로 옵니다. 아래 묶음 가운데 찾는 말이 있을 법한 곳을 열어 보세요.

  1. 컴퓨터와 연결: 일이 도는 곳과 그곳에 이어 붙는 말
  2. 프로젝트와 작업 자리: 일을 담는 그릇
  3. 세션과 에이전트: 에이전트와 하는 일과 그것을 정하는 말
  4. 상태: 세션과 연결과 작업 자리가 지금 어떤지 알려 주는 말
  5. 역할과 오케스트레이션: 일을 나누고 맡기는 말
  6. 받은 요청과 알림: 사람에게 오는 요청과 알림
  7. 워크플로: 되풀이되는 일을 단계로 적어 둔 것
  8. 이슈와 연결: Jira와 GitHub의 이슈
  9. 창과 화면 배치: 창의 부분과 탭의 배치
  10. 설정의 말: 설정 화면의 말
  11. 토큰과 캐시: 사용량을 읽는 말

컴퓨터와 연결

섹션 제목: “컴퓨터와 연결”

이 컴퓨터

섹션 제목: “이 컴퓨터”

Lyra 앱을 켠 컴퓨터입니다. 문장에서는 「이 컴퓨터」라고 하고, 이름표에서는 localhost라고 적습니다. 설정의 에이전트와 에이전트 스킬에서는 이 컴퓨터의 이름이 localhost이고, 메모리 칸에서는 이 컴퓨터의 여유 메모리를 보여 줍니다.

나오는 곳: 서버와 Host, 설정, 에이전트, 에이전트 스킬, 창 위쪽과 아래쪽

Host

섹션 제목: “Host”

일이 실제로 도는 컴퓨터입니다. 이 컴퓨터, 서버, WSL 배포판이 있습니다. 어느 Host에서 도는지는 줄 끝의 이름이나 점으로 알립니다.

나오는 곳: 서버와 Host, Home, 프로젝트 추가, 탐색기, Lyra 입력창

서버

섹션 제목: “서버”

SSH로 연결해 등록한 다른 컴퓨터입니다. 서버에서 에이전트를 돌리려면 서버에도 lyra-daemon이 있어야 하는데, 서버에 연결할 때 Lyra가 올려 주므로 Lyra를 따로 설치하지 않습니다.

나오는 곳: 서버와 Host, 원격, 설정

원격

섹션 제목: “원격”

서버의 연결을 가리키는 말입니다. 설정에서는 서버를 등록하는 화면의 이름이고, 아래쪽 상태 줄에서는 「원격 1/2」처럼 연결된 서버 수와 등록한 서버 수를 보여 주는 칸의 이름입니다.

나오는 곳: 원격, 서버와 Host, 창 위쪽과 아래쪽

배포판

섹션 제목: “배포판”

Windows 안에 깔린 Linux 하나입니다(WSL이라고 부르는 기능으로 돌립니다). 서버 줄 없이 이 컴퓨터 아래에 놓입니다. 설정에서는 WSL 배포판이라고 합니다.

나오는 곳: WSL, 서버와 Host

lyra-daemon

섹션 제목: “lyra-daemon”

에이전트와 터미널 프로세스를 띄우고 지키는 Lyra의 실행 엔진입니다. 일이 도는 컴퓨터마다 하나씩 있습니다.

나오는 곳: 서버와 Host, 에이전트, 원격, WSL, 앱

별칭

섹션 제목: “별칭”

연결을 부르는 이름입니다. 서버의 별칭은 ~/.ssh/config에서 고르는 서버 이름이고, Jira나 GitHub 연결의 별칭은 그 연결에 붙이는 이름입니다.

나오는 곳: 원격, 이슈 연결

인증

섹션 제목: “인증”

서버에 로그인하는 방식입니다. 연결 카드에서는 이슈 서비스에 로그인하는 방식을 가리키는 인증 방식도 있습니다.

나오는 곳: 원격, 이슈 연결

일회용 코드

섹션 제목: “일회용 코드”

서버가 로그인할 때 한 번 묻는 코드입니다(OTP라고도 합니다). 한 번 쓰면 못 쓰는 숫자입니다.

나오는 곳: 원격

프로젝트와 작업 자리

섹션 제목: “프로젝트와 작업 자리”

프로젝트

섹션 제목: “프로젝트”

Lyra에 등록한 저장소 또는 폴더입니다. 메뉴 제목에서는 Project라고 씁니다. Session과 작업 자리가 그 아래에 있습니다. Home의 「최근 프로젝트」, 워크플로 실행 창의 프로젝트도 이것입니다.
